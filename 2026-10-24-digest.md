## AI Design Tool от Anthropic: трекинг

### Статус: вышел из беты, доступен всем

**Хронология:**
- **17 апреля 2026** — запуск Claude Design как research preview на платных планах ([Anthropic](https://www.anthropic.com/news/claude-design-anthropic-labs))
- **Июнь 2026** — бета: добавлен импорт дизайн-систем из репозитория, дизайн-файлов или кодовой базы; round trip с Claude Code
- **17 августа 2026** — скилл `/design` в Claude Code CLI и Desktop (research preview)
- **16 сентября 2026** — Claude Design работает внутри обычных чатов Claude с доступом к контексту, файлам и коннекторам
- **8 октября 2026** — **выход из беты**, доступен на всех планах включая Free ([omidsaffari.com](https://omidsaffari.com/blog/claude-design-free))
- **15 октября 2026** — автовключение для Enterprise (кроме HIPAA-организаций)
- **14 декабря 2026** — закрытие standalone-версии на claude.ai/design

**Функциональность:**
- Генерация UI-прототипов, лендингов, слайд-презентаций из текстового описания
- Создание дизайн-систем за ~15 минут (токены, цвета, типографика, компоненты)
- Inline-редактирование на холсте + «Tweaks» для шрифтов, радиусов, отступов
- Handoff bundle → Claude Code для реализации
- Работает на Claude Opus 4.7

**Экспорт:** zip, PDF, PPTX, standalone HTML, Canva. Нативного экспорта в Figma пока нет — используются сторонние инструменты (Anima) или Code to Canvas.

**Интеграции:**
- **Figma**: через Code to Canvas (февраль 2026) — конвертация Claude Code UI в редактируемые фреймы; двусторонняя связь через Figma MCP (май 2026)
- **Canva**: партнёрство, прямой экспорт
- **Claude Code**: seamless handoff bundle
- **Word/PowerPoint**: экспорт PPTX

**Ценообразование:** входит во все планы Claude (Free, Pro $20/мес, Team $25/мес, Max $100/мес, Enterprise). Usage limits общие с чатом — это не отдельная подписка.

**Ограничения (по обзорам):**
- Ручное редактирование уступает профессиональным инструментам
- Слабая история версий
- Большой расход токенов (setup может потратить весь лимит)
- Генерация 4–7 минут на промпт
- Выход может быть «generic» без тщательного промптинга и дизайн-системы

**Конкуренты:**
- **v0 (Vercel)** — быстрее для одностраничных компонентов
- **Figma AI / Figma Make** — нативная экосистема, лучше для командной работы
- **Adobe Firefly** — фокус на контенте, не на UI
- **Canva** — партнёр, не конкурент

**Реакция сообщества:** Дизайнеры оценивают как отличный инструмент для идеации и быстрого прототипирования, но не замену Figma для production workflows. Главная ценность — скорость от идеи до рабочего прототипа и создание дизайн-систем с нуля.

## Выводы

### Что применить в работе дизайнера

1. **Claude Design теперь бесплатен** — можно начать экспериментировать без подписки. Рекомендуется первым делом загрузить дизайн-систему (или создать новую), иначе результат будет «generic AI».

2. **Трёхслойная система управления качеством** — системный промпт задаёт общий тон, Skill контролирует конкретное поведение, дизайн-система определяет визуальное качество. Без всех трёх слоёв результат нестабилен.

3. **Итеративный подход «по проходам»** — сначала IA и лейаут, потом типографика, потом цвет, потом микроинтеракции. Каждый проход — отдельный промпт. Это даёт контроль и предсказуемость.

4. ⭐ **ЗАПОМНИТЬ — Правило одной ошибки**: при работе с Claude Design указывай только одну проблему за раз, прикладывая скриншот в двух разрешениях (1440 и 390). Переделка всего приложения целиком ведёт к регрессиям. Этот принцип из китайского кейса (UISDC) подтверждается и в других источниках.

5. ⭐ **ЗАПОМНИТЬ — Структурированный контекст для дизайн-систем**: Claude видит имена и значения токенов, но не видит намерение. Нужно передавать описания токенов с правилами использования и примерами экранов. Это ключевая разница между «generic AI output» и качественным результатом (Headway, Mejba).

6. **Taste Skill 2.0** — значимое обновление дефолтного скилла вкуса. Стоит обновить до 2.1.2 и протестировать разницу.

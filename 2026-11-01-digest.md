## AI Design Tool от Anthropic — трекинг

### Статус на 1 ноября 2026

**Продукт:** Claude Design (запущен 17 апреля 2026 как Anthropic Labs research preview)

**Текущая доступность:**
- С 8 октября 2026 — доступен на всех планах (Free, Pro, Max, Ultra, Team, Enterprise)
- Standalone-версия (claude.ai/design) **закрывается 14 декабря 2026**
- Интегрирован в основной Claude: доступен в разговорах, через Artifacts, в Claude Code и Claude Desktop

**Функциональность:**
- Создание прототипов, слайдов, одностраничных документов и лендингов через диалог
- Импорт дизайн-системы из репозитория — применяет реальные цвета, типографику и компоненты
- Редактирование на холсте (добавлено в июне 2026)
- Синхронизация с Claude Code для передачи в разработку
- Работает на Claude Opus 4.7

**Интеграции:**
- **Figma:** двусторонняя интеграция через Code to Canvas (февраль 2026) — AI-код конвертируется в редактируемые Figma-слои
- **Claude Code:** прямая передача прототипов для имплементации
- Word и PowerPoint — были в планах на момент анонса, текущий статус не подтверждён

**Ценообразование:**
- Входит в подписку Claude (все тарифы включая Free)
- Предупреждение: один рецензент потратил 50% недельного лимита Pro на одну дизайн-систему + прототип

**Сравнение с конкурентами:**
- **vs Figma:** Claude Design для ранних стадий и исследования, Figma для продакшна и handoff. Акции Figma упали на 7% в день запуска
- **vs Figma AI/Make:** GitLab предпочёл Claude — мелкие правки без перегенерации экрана
- **vs v0/Bolt:** Claude Design генерирует «дизайны, не картинки» и может использовать реальную дизайн-систему
- Figma также заключила партнёрство с OpenAI (Codex) через неделю после Anthropic

**Реакция сообщества:**
- Дизайнеры видят как дополнение, а не замену Figma
- Качество зависит от загруженного контекста (дизайн-система, скриншоты, правила)
- ⭐ **Ключевое:** закрытие standalone-версии 14 декабря — дизайн-системы нужно мигрировать

## Выводы

### Что применить в работе дизайнера

1. **Миграция дизайн-систем из Claude Design** — ⭐ **ЗАПОМНИТЬ**. Standalone закрывается 14 декабря. Чаты и комментарии не переносятся, проекты — без пути миграции. Действовать нужно сейчас: перенести дизайн-системы, скачать важные проекты.

2. **Claude Design как первый слой воркфлоу** — инструмент работает лучше всего на ранних стадиях: исследование вариантов, питчи, прототипы для обсуждения. Далее — Figma для продакшна. Подход Nate Parrott: «уровень выше продуктового дизайна».

3. **Дизайн-система как обязательный контекст** — ⭐ **ЗАПОМНИТЬ**. Без загруженной дизайн-системы Claude Design отклоняется от продукта. С ней — строит прототипы из реальных компонентов. Это подтверждают GitLab, Brilliant и независимые обзоры.

4. **CLAUDE.md как governance** — файл конфигурации Claude Code может хранить правила дизайн-системы, токены и ограничения. Это даёт ИИ постоянный контекст без повторных объяснений в каждом диалоге.

5. **Конкретные контролы вместо расплывчатого фидбэка** — приём Nate Parrott: вместо «сделай теплее» попросить Claude создать слайдеры для управления параметрами. Применимо к работе с клиентами и стейкхолдерами.

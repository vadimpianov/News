**[Claude Design vs Figma Make: 2026 AI Design Tool Comparison](https://www.eigent.ai/blog/claude-design-vs-figma-make)** — Eigent

**Суть:** Серия сравнений двух AI-инструментов для дизайнеров:
- **Claude Design** — сильнее в generation from scratch, code-powered прототипах, поддержке кодовой базы и дизайн-систем. Работает через диалог, не через канвас. Экспорт: HTML, PDF, PPTX, Canva.
- **Figma Make** — сильнее в интерактивных прототипах со стейтами и переходами, multiplayer-коллаборации, нативной связке с Dev Mode и Code Connect. Работает на Sonnet 4/4.5.
- **Вывод рецензентов:** Claude Design — комплемент к Figma для профессиональных дизайнеров. Для PM, разработчиков и фрилансеров, которым нужны визуалы без изучения Figma, — может быть полноценной заменой.

## AI Design Tool от Anthropic — трекинг

### Статус: Claude Design вышел из беты, standalone закрывается 14 декабря

- **Релиз:** Claude Design запущен 17 апреля 2026 как research preview от Anthropic Labs. На 8 октября 2026 вышел из беты и доступен на всех планах, включая Free.
- **Standalone-версия** (claude.ai/design) прекращает работу **14 декабря 2026**. Функциональность переносится в основной интерфейс Claude.
- **Enterprise:** Включается по умолчанию **15 октября 2026**.
- **Функциональность:** Генерация прототипов, презентаций, one-pagers через диалог. On-canvas editing с дизайнерской лексикой (tracking, not letter-spacing). Импорт дизайн-систем из GitHub, Figma, загруженных файлов. Экспорт: HTML, PDF, PPTX, Canva. Handoff в Claude Code через `/design`. Новое: Claude Motion для анимаций (Team/Enterprise).
- **Интеграции:** Figma — через MCP (Code Connect, Code to Canvas). Партнёрство с Figma анонсировано в феврале 2026 (Code to Canvas — конвертация AI-кода в редактируемые Figma-файлы). Нативный экспорт в Figma пока отсутствует.
- **Ценообразование:** Входит в подписку Claude (Free, Pro, Max, Team, Enterprise). Лимиты на использование — частая жалоба (Max 5x подписчики исчерпывают недельный бюджет Design за пару сессий).
- **Сравнение с конкурентами:** Claude Design vs Figma Make — Claude сильнее в code-powered генерации, Figma Make — в интерактивных прототипах и коллаборации. v0 (Vercel) — более узкий фокус на веб-компонентах. Adobe Firefly — другая ниша (генеративные медиа).
- **Реакция сообщества:** Профессиональные дизайнеры скептичны к замене Figma, но признают ценность для быстрого прототипирования. PM и разработчики более энтузиастичны. Акции Adobe, Wix, Figma падали на 2%+ после анонса.

## Выводы

### Что применить в работе дизайнера

1. **Claude Design вышел из беты** — самое время попробовать в рабочем проекте, если откладывали. Теперь доступен даже на Free-плане. Standalone-версия закроется 14 декабря — стоит начать миграцию дизайн-систем заранее.

2. **Claude Motion для анимированных демо** — ⭐ **ЗАПОМНИТЬ**. Новый инструмент для создания анимированных объяснений из графиков и отчётов. Для продуктовых дизайнеров это потенциально мощный способ презентовать дата-инсайты и UX-решения стейкхолдерам. Пока только на Team/Enterprise.

3. **Итеративный подход к промптингу** — не пытаться получить идеальный экран за один промпт. Лучше: (1) информационная архитектура → (2) визуальная иерархия и типографика → (3) интерактивные детали. Этот подход подтверждают и китайские, и японские, и западные источники.

4. **Явные дизайн-правила вместо «сделай красиво»** — Reddit-дискуссии и обзоры подтверждают: Claude даёт лучшие результаты, когда получает конкретные параметры (контраст, spacing, font sizes), а не абстрактные запросы.

5. **Дизайнер Anthropic: начинай с дизайн-системы** — инсайт из гайда RAR Design: построить ядро системы и базовые страницы первыми, а потом масштабировать. Не наоборот.

## Выводы

### Главные паттерны дня

1. **Трёхуровневый воркфлоу** — Artifacts (исследование) → Lovable (построение) → Claude Code + Figma MCP (точность). Дизайнеры больше не выбирают один инструмент.

2. ⭐ **ЗАПОМНИТЬ: «Generic AI-дизайн — это проблема промпта, не модели»**
   Передавай Claude философию дизайн-системы (токены, компоненты, принципы) до генерации — это ключевое открытие недели. Официальный frontend-design skill Anthropic (277k+ установок) решает это системно.

3. **Роль дизайнера меняется** — от «пикселей» к «курированию и стратегии». AI берёт токены, аудиты, документацию; дизайнер — системное мышление.

4. **Figma — не конец, а центр** — несмотря на конкуренцию со стороны Anthropic Design Tool, Figma стала хабом для AI-агентов (открыла канвас для записи). Это неожиданный поворот.

5. **Super-IC реален** — старшие дизайнеры выдают объём команды из 3 человек. Это меняет hiring-стратегии компаний.

### Применимые приёмы прямо сейчас

- Установить [Figma MCP Server](https://www.figma.com/blog/introducing-claude-code-to-figma/) и попробовать создать один компонент из терминала
- Начинать с компонента, не со страницы — Claude даёт точнее результаты на ограниченном контексте
- Передавать в промпт токены своей дизайн-системы перед любой генерацией UI

## AI Design Tool от Anthropic — трекинг

### Статус продукта
- **Название:** Claude Design (подразделение Anthropic Labs)
- **Дата анонса:** 17 апреля 2026 (одновременно с релизом Claude Opus 4.7)
- **Статус:** Research Preview (исследовательский превью)
- **Доступность:** Claude Pro ($20/мес), Max ($100–200/мес), Team ($25/место), Enterprise

### Функциональность
- Генерация прототипов, лендингов, презентаций, питч-деков, one-pagers через диалог
- Работает на Claude Opus 4.7 — vision-модель, оптимизированная для UI-генерации
- Автоматическое извлечение дизайн-системы из кодовой базы и Figma-файлов при онбординге
- Поддержка voice, video, шейдеров, 3D, встроенных AI-вызовов
- Inline-комментарии, слайдеры для тонкой настройки, прямое редактирование
- Экспорт: PDF, PPTX, HTML, Canva, handoff bundle в Claude Code

### Интеграции
- **Figma:** Коннектор Code to Canvas (совместная разработка с Figma, запущен в феврале 2026). Конвертирует код из Claude Code в редактируемые Figma-дизайны
- **Canva:** Экспорт дизайнов напрямую в Canva
- **Adobe Creative Cloud:** 50+ инструментов (Photoshop, Premiere, Express) — коннектор запущен конец апреля 2026
- **Blender:** Natural-language интерфейс к Python API Blender
- **Autodesk Fusion:** Создание и модификация 3D-моделей через диалог
- **Ableton, Affinity, Splice, SketchUp, Resolume** — новые коннекторы

### Ценообразование
- Включён в текущие подписки Claude Pro/Max/Team/Enterprise без дополнительной платы
- **Важно:** Потребляет токены очень быстро — Pro-пользователь может исчерпать недельный лимит за 30 минут использования
- Лимиты Claude Design считаются отдельно от чат-лимитов

### Стратегический контекст
- Mike Krieger (CPO Anthropic) покинул совет директоров Figma 14 апреля 2026, за 3 дня до запуска Claude Design
- Акции Figma упали на 7% в день запуска
- Anthropic позиционирует Claude Design как инструмент для interoperability, а не замену Figma/Adobe
- Образовательные партнёрства: RISD, Ringling College, Goldsmiths (Лондон)
- Anthropic сделал пожертвование в фонд разработки Blender

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Design System as Code** — Загружайте свою дизайн-систему в Claude Design при онбординге. Модель извлечёт цвета, типографику и компоненты из вашей кодовой базы и Figma-файлов, обеспечивая автоматическую консистентность в каждом новом проекте.

2. **Claude Skills для борьбы с «AI-шным» видом** — Создавайте markdown-файлы (skills) с жёсткими правилами дизайна: точные палитры, типографические шкалы, запреты на избыточные градиенты и декорации. Это решает главную проблему AI-дизайна — генерический вид.

3. **Замкнутый цикл: Claude Design → Claude Code** — Используйте handoff bundle для передачи готовых дизайнов напрямую в Claude Code. Это устраняет ручной перевод дизайна в код и минимизирует потери при передаче.

4. **«AI Direction» как новый навык** — Инвестируйте время не в изучение горячих клавиш новых инструментов, а в навык точного описания желаемого результата. Конкретность и вкус в промптах дают лучший результат, чем техническая виртуозность в инструменте.

5. ⭐ **ЗАПОМНИТЬ: Правило 2 промптов vs 20** — Старший дизайнер Anthropic обнаружил, что сложные страницы, требующие 20+ промптов в конкурирующих инструментах, воспроизводятся за 2 промпта в Claude Design. Причина — удержание контекста дизайн-системы. **Это значит, что инвестиция времени в качественный онбординг дизайн-системы окупается экспоненциально** — чем точнее ваши constraints, тем меньше итераций нужно на каждый экран.

6. ⭐ **ЗАПОМНИТЬ: Архитектура многослойных воркфлоу** — Создавайте трёхуровневую систему: справочные знания (дизайн-принципы) → capability workflows (конкретные процессы) → tool connectors. При обновлении принципов на верхнем уровне все зависимые воркфлоу обновляются автоматически. **Это решает проблему «дрейфа» дизайн-системы в больших командах.**

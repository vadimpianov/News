## 1. Figma-техники

- **Принцип:** Перед началом работы Claude Code с Figma-канвасом запускайте Preflight-скилл, который строит Token Map и Component Registry — пока чеклист не пройден, ни один нод не создаётся.
- **Почему:** Без Preflight Claude Code подставляет захардкоженные hex-цвета и сырые числа вместо дизайн-токенов, а обнаруживается это только через 30 минут потерянной работы.
- **Источник:** [How to make Claude Code follow your design system in Figma — Sen Lin, UX Collective](https://uxdesign.cc/how-to-make-claude-code-follow-your-design-system-in-figma-559618cffaa9)
- **Дата:** 2026-05-14

## 2. Компоненты & Паттерны

- **Принцип:** Держите design.md отдельно от CLAUDE.md как «исполняемую версию» бренд-гайдлайнов — с дизайн-токенами, type scale, spacing-правилами и перечнем компонентов.
- **Почему:** Когда дизайн-система зафиксирована в отдельном файле, Claude Code применяет правила автоматически и не тратит токены на повторное инферирование стилей в каждом сеансе.
- **Источник:** [デザイナーがClaude Codeを使い倒すための18のショートカット＆コマンド — 大原かほ, note.com](https://note.com/ohara_designer/n/n3742df6f287b)
- **Дата:** 2026-05-14

## 3. Компоненты & Паттерны (Анти-паттерн)

- **Принцип:** Generic design.md — это старт, не финиш: для production-воркфлоу кастомизируйте скиллы Claude Code под конкретную команду, включая шаблоны layout'ов, иерархию шрифтов и бренд-цвета.
- **Почему:** Студия из 6 человек обнаружила, что стандартные скиллы генерируют «средний» результат, а кастомизированные — сразу production-ready слайды с правильными стилями, стрелками и таблицами.
- **Источник:** [Claude Codeの汎用 design.md スキルは素晴らしい。でも僕らは自社用に作り直した — picks design / 松浦, note.com](https://note.com/kyatap01/n/nfa0188eef2a0)
- **Дата:** 2026-05-14

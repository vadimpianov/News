## 1. Figma-техники

- **Принцип:** Используй `create_design_system_rules` в Figma MCP, чтобы создать файл правил один раз — Claude будет следовать конвенциям команды (именование токенов, структура папок, паттерны компонентов) во всех последующих задачах автоматически.
- **Почему:** Без файла правил Claude генерирует компоненты с произвольными именами и структурой, что приводит к рассинхронизации с дизайн-системой и ручной переделке.
- **Источник:** https://uxdesign.cc/how-to-make-claude-code-follow-your-design-system-in-figma-559618cffaa9
- **Дата:** 2026-05-17

## 2. Компоненты & Паттерны

- **Принцип:** При AI-генерации UI создавай Claude Skills (markdown-инструкции) с точной стилизацией, палитрами и типографикой — это устраняет характерный «AI-шный» вид интерфейсов и делает результат неотличимым от работы профессионального дизайнера.
- **Почему:** Без явных стилевых инструкций AI-модели генерируют усреднённый визуал с типичными паттернами (избыток градиентов, generic цвета, однообразные отступы), который мгновенно распознаётся как «сделанный ИИ».
- **Источник:** https://www.hexabase.com/column/ai-design-claude-skills-workflow
- **Дата:** 2026-05-17

## 3. Spacing & Layout

- **Принцип:** Для визуального тюнинга (spacing density, типографика, порядок секций) используй неинтерактивные слайдеры (Tweaks) вместо чат-промптов — это экономит 30–50% бюджета токенов и даёт мгновенный визуальный фидбек без задержки на обращение к модели.
- **Почему:** Чат-промпты для мелких визуальных корректировок (подвинуть отступ, изменить размер шрифта) неэффективны: каждый требует полного цикла обработки моделью, что расходует токены и замедляет итерацию в 5–10 раз по сравнению с прямой манипуляцией.
- **Источник:** https://muz.li/blog/claude-design-one-week-in-hacks-best-practices-tips-from-real-world-use/
- **Дата:** 2026-05-17

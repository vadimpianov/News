### 9. Claude Design vs Figma Make vs v0 — актуальное сравнение
**[Figma Make vs Stitch vs Claude Design vs v0 vs Lovable](https://mowgli.ai/blog/figma-make-vs-stitch-vs-claude-design-vs-v0-vs-lovable)** — Mowgli

**Суть:** Консенсус рынка:
- **Claude Design** — лучше для не-дизайнеров, быстрых прототипов, презентаций. Экспорт: PPTX, PDF, HTML, Canva. Нет нативного экспорта в Figma.
- **Figma Make** — для команд в экосистеме Figma. Результат остаётся редактируемым в Figma. Требует Full seat на платном плане.
- **v0** (Vercel) — ориентирован на разработчиков. Выход: React/Next.js на shadcn/ui.
- **Stitch** (Google) — аналогичный подход с Gemini.

Claude Design выигрывает в conversational-подходе и design-system onboarding, проигрывает в precision control и collaboration.

### 10. 10 советов для лучших результатов в Claude Design
**[10 Tips for Getting Better Results from Claude Design](https://blog.infernored.com/10-tips-for-getting-better-results-from-claude-design/)** — InfernoRed

**Суть:** Практические советы:
- Chat — для структурных/концептуальных изменений; Tweaks — для spacing, цвета, типографики
- Описывайте желаемый вид, а не то, чего хотите избежать («тёплый минимализм» > «не используй кремовый фон»)
- Загружайте реальную страницу или готовую презентацию, а не только hex-коды — Claude считывает «эмоциональную текстуру бренда»
- Запрашивайте несколько вариантов для одной секции
- Финальную вёрстку передавайте в Claude Code — это быстрее и дешевле, чем итерировать визуально

## Выводы

### Что применить в работе дизайнера

1. **Claude Design теперь бесплатен** — можно тестировать прототипы и лендинги без подписки. Лимиты скромные, но для быстрой проверки идеи достаточно.

2. **Разделение режимов взаимодействия** — ⭐ **ЗАПОМНИТЬ**. Chat для структуры и концепции, inline comments для точечных правок (padding, компоненты), Tweaks для spacing/цвета/типографики. Это не просто UX Claude Design — это паттерн для любого AI-инструмента: разные типы задач требуют разных модальностей ввода.

3. **Design system onboarding перед прототипированием** — загрузка существующего кода или дизайн-файлов в Claude Design перед началом работы критически важна для получения консистентных результатов. Без этого шага всё выглядит «AI-генерированным».

4. **Миграция с standalone до 14 декабря** — если используете claude.ai/design, экспортируйте проекты сейчас. Чаты и комментарии не мигрируются.

5. **Claude Motion для product-дизайнеров** — новый канал для создания анимированных объяснений без видеоредактора. Пока бета, но стоит попробовать для внутренних презентаций и onboarding-материалов.

### Claude Motion — анимированные объяснялки без видеомодели

**Суть:** Claude Motion создаёт короткие анимированные объяснения из текстового запроса. Выходной формат — код, не генеративное видео: нет ИИ-сгенерированных людей или стокового футажа. Доступен по команде `/motion` в чате. Бета на планах Team ($25/seat/мес, минимум 2 места) и Enterprise. Рецензент Eesel.ai поставил высший балл за редактирование и низший — за диапазон выходных форматов (нет озвучки и стокового видео).

## AI Design Tool от Anthropic — трекинг

### Статус: Design вышел из беты, standalone-сайт закрывается

**Хронология:**
- **Февраль 2026:** Figma и Anthropic объявляют партнёрство — фича [Code to Canvas](https://www.cnbc.com/2026/02/17/figma-anthropic-ai-code-designs.html) конвертирует код из Claude Code в редактируемые дизайны в Figma.
- **Апрель 17, 2026:** Anthropic запускает [Claude Design](https://venturebeat.com/technology/anthropic-just-launched-claude-design-an-ai-tool-that-turns-prompts-into-prototypes-and-challenges-figma/) (research preview) — генерация сайтов, лендингов, презентаций из промптов. Работает на Claude Opus 4.7.
- **Май 2026:** Figma [расширяет партнёрство](https://dataconomy.com/2026/05/21/figma-ai-design-agent-openai-anthropic-integrations/) с Anthropic и OpenAI, интегрируя CLI-инструменты (Claude Code, Codex) в свой софт.
- **Сентябрь 16, 2026:** Design интегрирован в основной интерфейс Claude (каждый разговор).
- **Октябрь 8, 2026:** [Design выходит из беты](https://claude.com/resources/articles/dashboards-and-motion) — доступен на ВСЕХ планах, включая Free. Standalone-сайт claude.ai/design закрывается 14 декабря 2026.

**Функциональность:**
- Генерация UI, лендингов, презентаций, прототипов из текста
- Встроенная дизайн-система (читает кодовую базу, извлекает цвета, типографику, spacing, компоненты)
- Редактирование через чат, инлайн-комментарии, прямые правки, слайдеры
- Экспорт: HTML, PDF, PPTX, Canva, Google Slides (редактируемый), хендофф в Claude Code
- Мобильное редактирование в Claude app

**Новое (октябрь 2026):**
- Design теперь на Free плане — порог входа для дизайнеров снижен до нуля
- Enterprise CMEK поддержка для артефактов
- Совместное редактирование с Claude в команде
- Шеринг за пределы организации (если разрешено администратором)
- Дефолтное включение для Enterprise — 15 октября

**Ценообразование:** Включён в подписку. Free — ограниченное использование. Pro, Max, Team, Enterprise — больше лимитов. Расходует общий бюджет использования плана (вместе с чатом, Code, Cowork).

**Интеграции:** Figma (Code to Canvas, MCP-сервер), Canva, Google Slides, PDF, PPTX, Claude Code (хендофф).

**Сравнение с конкурентами:**
- **vs Figma Make:** Claude Design генерирует рабочий код (HTML/CSS/JS); Figma Make — point-and-edit в канвасе Figma. Комплементарные инструменты.
- **vs Adobe Firefly:** Claude Design — текст→прототип→код; Firefly — генерация графики. Разные ниши.
- **vs v0 (Vercel):** Оба генерируют код из промптов, но Claude Design интегрирован в экосистему Claude (Code, Docs, Slides).

**Реакция дизайн-сообщества:** Смешанная. Опытные дизайнеры принимают как инструмент идеации и быстрого прототипирования, но подчёркивают, что для пиксельного контроля и работы с дизайн-системой Figma остаётся основной. GA на Free плане — позитивный сигнал для демократизации дизайна.

## Выводы

### Что применить в работе дизайнера

1. **Claude Design теперь бесплатный** — можно использовать для быстрого прототипирования идей без подписки. Начинать с создания дизайн-системы (при первом запуске) — иначе вывод будет generic.

2. **Claude Motion для объяснялок** — если нужно быстро создать анимированный разбор фичи для стейкхолдеров или all-hands, Motion генерирует редактируемую анимацию из текста. Каждый элемент правится отдельно.

3. **Dashboards для дизайнерского исследования** — продуктовый дизайнер может подключить BigQuery/Amplitude и задать вопрос на естественном языке, получить визуализацию без помощи аналитика.

4. ⭐ **ЗАПОМНИТЬ — Всегда начинай Claude Design с загрузки дизайн-системы.** Несколько источников независимо подтверждают: без загруженных бренд-ассетов, цветов и компонентов Claude выдаёт шаблонный, generic результат. С дизайн-системой — результат on-brand и ближе к продакшену. Это самый высокоотдачный совет из всех найденных материалов.

5. ⭐ **ЗАПОМНИТЬ — Claude Design → Claude Code хендофф работает лучше с подключённой кодовой базой.** При экспорте из Design в Code, Claude Code уже понимает компоненты и паттерны прототипа — итераций меньше, результат чище.

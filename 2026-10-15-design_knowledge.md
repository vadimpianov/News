## 2. Figma-техники

**Принцип:** Разделяй Figma и Claude Code по задачам: Figma — для нового дизайна с нуля, Storybook + Claude Code — для итераций на существующем UI.

**Почему:** Goodpatch показали, что смешение инструментов замедляет процесс, а чёткое разделение по типу задачи ускоряет и дизайн, и разработку.

## 3. Компоненты & Паттерны

## AI Design Tool от Anthropic: трекинг

### Текущий статус (май 2026)

**Продукт:** Claude Design by Anthropic Labs  
**Дата запуска:** 17 апреля 2026 (Research Preview)  
**Модель:** Claude Opus 4.7 (специально оптимизирована для визуального дизайна)

### Доступность
- Research Preview (бета)
- Доступен для подписчиков Claude Pro ($20/мес), Max ($100/$200/мес), Team ($30/мес), Enterprise (кастом)
- GA дата не объявлена

### Функциональность
- Генерация прототипов, слайдов, one-pagers, лендингов, маркетинговых материалов через чат
- Автоматическое извлечение дизайн-системы из кодовой базы и дизайн-файлов
- Inline-комментарии, прямое редактирование, автогенерируемые слайдеры (spacing, цвет, типографика)
- Хендофф в Claude Code в виде структурированного бандла

### Экспорт и интеграции
- PDF, PPTX, HTML, Canva
- **Нет нативного экспорта в Figma** (главное ограничение)
- Через Claude Code to Figma — код конвертируется в редактируемые Figma-слои
- Через html.to.design и Anima — обходные пути для Figma-импорта
- **Нет экспорта в Word/PowerPoint** (только PPTX через общий экспорт)

### Ценообразование
- Входит в подписку Claude Pro/Max/Team/Enterprise
- Отдельная еженедельная квота, не пересекающаяся с Claude Code
- На Pro-плане токены расходуются быстро при работе с дизайн-системами

## Выводы

### Применимые приёмы для работы дизайнера

1. **Дизайн-система из кода, а не из описания.** Направляйте Claude Design на ваш UI-пакет / кодовую базу — это даёт значительно более точный и бренд-согласованный результат, чем словесные описания цветов и шрифтов.

2. **Разделение инструментов по этапам.** Claude Design — для визуального исследования и вариаций. Claude Code — для продакшн-реализации. Не смешивайте: это главная ошибка новичков, сжигающая время и токены.

3. **Сравнение вместо итерации.** Когда не уверены в направлении — просите вариации, а не правки одного варианта. Сравнение экспоненциально быстрее линейного угадывания.

4. **Слайдеры вместо чата.** Spacing, цвет, типографика — используйте Tweaks-панель. Каждое сообщение в чат стоит токенов; слайдер — бесплатен.

5. **Борьба с AI slop.** Выбирайте один решительный, нетривиальный шрифт. Создавайте палитру с чёткой доминантой и акцентами, а не «равномерное распределение всех цветов». Избегайте Inter, бело-фиолетовых градиентов и «Stripe-стиля».

6. ⭐ **ЗАПОМНИТЬ: Design Review через Playwright MCP.** Claude Code открывает headless-браузер, проходит все страницы, делает скриншоты и запускает design review skill автономно. Это автоматизация QA для дизайна, которая ловит нарушения дизайн-системы до отправки в продакшен. Идея из статьи Julian Oczkowski — может радикально изменить дизайн-ревью процесс.

7. ⭐ **ЗАПОМНИТЬ: Час на настройку дизайн-системы = экономия дней.** Совет сотрудника Anthropic: один час тщательной настройки дизайн-системы и ключевых экранов окупается многократно на каждом следующем проекте. Особенно актуально при обслуживании нескольких продуктов.

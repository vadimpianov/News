### Как заставить Claude Code следовать вашей дизайн-системе в Figma
**[How to make Claude Code follow your design system in Figma](https://uxdesign.cc/how-to-make-claude-code-follow-your-design-system-in-figma-559618cffaa9)** — Sen Lin, UX Collective, май 2026

**Суть:** Ключевая проблема: Claude Code умеет вызывать Figma API, но не знает правил конкретного проекта — использует hex-значения вместо токенов (например, #5C6AC4 вместо color/brand/primary), не переиспользует компоненты из библиотеки. Фреймворк обеспечивает compliance дизайн-системы при каждой AI-генерации. Claude Code становится ассистентом дизайнера, чей вывод можно модифицировать и итерировать.

## AI Design Tool от Anthropic: трекинг

### Статус: Research Preview (бета)
- **Дата запуска:** 17 апреля 2026
- **Доступность:** Research preview для Claude Pro ($20/мес), Max ($100/$200/мес), Team, Enterprise. Постепенный rollout.
- **Модель:** Claude Opus 4.7

### Функциональность
- Генерация интерактивных прототипов, слайд-деков, лендингов, one-pagers из текстового описания
- Hover-состояния, переходы, навигация, multi-screen flows
- Инлайн-комментарии, прямое редактирование текста, кастомные слайдеры (spacing, color, layout)
- Онбординг: считывает кодовую базу и дизайн-файлы → строит дизайн-систему (цвета, типографика, компоненты)
- Handoff bundle → Claude Code для перехода к разработке

### Ограничения (актуальные на май 2026)
- Высокий расход токенов — Pro-лимит (~3-4 сложных промпта в неделю)
- Нет мультиплеерной коллаборации
- Нет нативного экспорта в .fig — только через Figma Code to Canvas
- Нет публичного API
- Tweak-панель нестабильна
- Навигация по итерациям затруднена, Redo может не работать

### Экспорт
- PDF, PPTX, standalone HTML, Canva, внутренний URL
- В Claude Code через handoff bundle

### Интеграции
- **Figma:** Через Code to Canvas (февраль 2026) — конвертация кода в редактируемые Figma-дизайны
- **Canva:** Прямой экспорт + Brand Kit интеграция через Claude for Small Business (май 2026)
- **Microsoft:** Экспорт в PPTX; Word/PowerPoint интеграция в планах

### Ценообразование
- Входит в подписку Claude Pro/Max/Team/Enterprise без доп. оплаты
- Отдельный недельный бюджет токенов, который быстро расходуется
- Pro: ~10-40 промптов за окно; Max 5x: ~225; Max 20x: ~900

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Claude Code Skills для Figma compliance** — создайте набор из 4 Skills (токены, компоненты, layout, naming), чтобы AI-генерация всегда соответствовала вашей дизайн-системе. Это решает главную боль: Claude пишет hex вместо токенов.

2. **Claude Design → Claude Code → Figma Code to Canvas** — используйте полный цикл: быстрый прототип в Claude Design, реализация в Claude Code, импорт в Figma через Code to Canvas для доработки. Это самый полный AI-assisted воркфлоу на май 2026.

3. **Не задерживайтесь в Claude Design** — токены дорогие. Как только есть перспективный дизайн, переходите в Claude Code. Claude Design — для skip blank canvas phase, не для финального продакшна.

4. **Brand Kit + Canva в Claude** — для маркетинговых материалов (посты, рекламные креативы) можно генерировать on-brand контент прямо из Claude через Canva-коннектор. Дизайнеру остаётся настроить Brand Kit один раз.

5. ⭐ **ЗАПОМНИТЬ: Роль дизайнера смещается от создания к управлению системой.** Claude Design, Canva-интеграция и автогенерация из Brand Kit означают, что не-дизайнеры будут создавать визуальный контент. Ценность дизайнера — в создании и поддержке системы (дизайн-токены, компоненты, Brand Kit, правила), а не в ручном производстве каждого ассета. Это подтверждается и статистикой: сеньор-дизайнеры с AI выдают объём работы команды из 3 человек.

## AI Design Tool от Anthropic — трекинг

### Статус: Claude Design интегрирован в основной продукт

Ключевые события октября 2026:

1. **Закрытие standalone-версии.** Отдельный сайт claude.ai/design закроется **14 декабря 2026**. Дизайн-системы из него нужно мигрировать заранее — они переносятся в артефакты и доступны в любом чате, включая Claude Code.
   - [Get started with Claude Design](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

2. **Enterprise по умолчанию.** С **15 октября 2026** Claude Design включён по умолчанию для Enterprise-планов.

3. **Редизайн интерфейса Claude (23 октября 2026).** По данным китайского ресурса, команда Anthropic использовала Claude и внутреннюю дизайн-систему, чтобы пройти путь от скетча до релиза менее чем за 3 недели.
   - [Claude 应用推出焕新界面](https://www.locdd.com/t/topic/103738)

4. **Текущие возможности** (по данным бета-обзоров октября):
   - On-canvas editing, design-system imports, Claude Code handoff
   - Экспорт: PDF, PPTX, HTML, Canva
   - Коннекторы: Adobe, Base44, Canva, Gamma, Lovable, Miro, Replit, Vercel, Wix
   - Нативного экспорта в Figma **нет** — только через сторонние инструменты (Anima Buddy)

5. **Ценообразование:** Разделяет лимиты с основным Claude (чат, Claude Code, Cowork). Доступен на Pro, Max, Team, Enterprise.

6. **Сравнение с конкурентами:**
   - **vs Figma:** Claude Design лучше для быстрых концептов и exploration; Figma сильнее в контроле, компонентных библиотеках, коллаборации и version history
   - **vs v0/Lovable:** Claude Design ближе к полноценному дизайн-инструменту, а не генератору кода
   - Акции Figma упали на ~6% после запуска Claude Design в апреле; Mike Krieger (CPO Anthropic) покинул борд Figma 14 апреля 2026
   - [Figma vs Claude Design — Lollypop, октябрь 2026](https://lollypop.design/blog/2026/october/figma-vs-claude-design/)
   - [Anthropic faces tensions with Figma](https://cryptobriefing.com/anthropic-figma-tensions-design-tools/)

## Выводы

### Что применить прямо сейчас

1. **Мигрировать дизайн-системы из standalone Claude Design** до 14 декабря 2026. Системы переносятся в артефакты и работают в любом чате — это улучшает связку с Claude Code.

2. **Описывать целые user flows, а не отдельные экраны** — трёхшаговый подход из UX Planet значительно улучшает качество output. Сначала flow, потом экраны в контексте, потом связки.

3. **Модульная установка скиллов** — не ставить всё сразу. Один скилл для design direction (`frontend-design`), другой для visual quality (`Taste Skill`), третий для проверок. Это уменьшает "AI slop" в результатах.

4. ⭐ **ЗАПОМНИТЬ — Claude проверяет output против дизайн-системы до показа.** Если импортировать дизайн-систему через `/design-sync`, Claude сам корректирует цвета, типографику и компоненты. Это резко снижает количество ручных правок. Особенно полезно для команд с established brand guidelines.

5. ⭐ **ЗАПОМНИТЬ — Question-driven design process.** Builder.io и HN-обсуждение отмечают: Claude Design задаёт вопросы перед генерацией, а не сразу выдаёт результат. Это вынуждает дизайнера чётче формулировать требования и создаёт более осмысленные артефакты. Принцип можно применить и в обычной работе: сначала вопросы, потом решение.

6. **Coded prototypes > Figma wireframes для тестирования** — опыт thoughtbot и Notion показывает, что clickable-прототипы на реальном коде дают лучший фидбек от пользователей, чем статичные mockups.

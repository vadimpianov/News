# Предложенные дизайн-принципы — 2026-10-31

## 1. Компоненты & Паттерны

- **Принцип:** При AI-генерации интерфейсов дизайнер должен работать с контекстом реального проекта (токены, компоненты, CLAUDE.md), а не с абстрактным промптом — иначе результат потребует полной переработки.
- **Почему:** Команда Knak показала, что дизайнер, работающий в кодовой базе с профилем и навыками, получает прототипы, которые минимально отличаются от production-кода, в то время как абстрактные макеты создают скоуп-дрифт и расхождения в оценках.
- **Источник:** [How Knak's Designers Prototype Directly in the Codebase](https://knak.com/blog/claude-code-streamlining-at-knak/)
- **Дата:** 2026-10-31

## 2. Figma-техники

- **Принцип:** Разделяй фазу дизайн-эксплорации (Claude Design) и фазу имплементации (Claude Code) в отдельные разговоры — смешение в одном потоке ухудшает качество обоих выходов.
- **Почему:** Автор пошагового гайда Design Systems Collective обнаружил, что Claude теряет фокус и начинает генерировать гибридные ответы (ни дизайн, ни код) при попытке совмещать обе фазы в одном чате. Чёткое разделение даёт лучший результат на каждом этапе.
- **Источник:** [From Prompt to Production: A Designer's Step-by-Step Workflow](https://www.designsystemscollective.com/from-prompt-to-production-a-designers-step-by-step-workflow-with-claude-design-claude-code-a7705daad026)
- **Дата:** 2026-10-31

## 3. Цвет

- **Принцип:** При AI-генерации UI всегда проверяй контраст цветов в первых черновиках — AI склонен занижать контраст и использовать шаблонные фиолетовые градиенты.
- **Почему:** Обзор 20 лучших Claude Code Skills для UI/UX отмечает, что Claude в первых итерациях систематически ошибается с контрастом. Существуют специальные правила (встроенные в skills), которые блокируют шаблонные шрифты и «фиолетовые градиенты» — но без ручной проверки WCAG-контраста первый черновик может не пройти аудит доступности.
- **Источник:** [The 20 Best Claude Code Skills for UI/UX Design](https://pasqualepillitteri.it/en/news/576/claude-code-skills-design-uiux-guide)
- **Дата:** 2026-10-31

## AI Design Tool от Anthropic: трекинг

### Статус: GA (General Availability) с 8 октября 2026

**Ключевые обновления:**
- **Релиз:** Claude Design вышел из беты 8 октября 2026. Доступен на всех тарифах (Free, Pro, Max, Team, Enterprise).
- **Enterprise:** Включён по умолчанию с 15 октября 2026. Админы могут включить раньше через Organization settings > Artifacts.
- **Standalone-версия:** claude.ai/design закрывается 14 декабря 2026. Дизайн-системы нужно перенести в основной Claude до этой даты.
- **Интеграция в Claude:** Design теперь работает внутри обычных чатов Claude и через Claude Code (команда `/design`). С середины сентября 2026 доступен как таб в интерфейсе.
- **Функциональность:** Генерация прототипов, слайдов и маркетинговых материалов из промптов. Поддержка дизайн-систем из репозитория. Хендофф-бандлы для Claude Code. Экспорт в PPTX, PDF, Canva.
- **Ограничения:** Нет нативного экспорта в Figma (используется сторонний плагин html.to.design). Нет полноценной истории версий. Лимиты использования общие с чатом, Claude Code и Cowork. Multi-person editing ограничен.
- **Модель:** Работает на Claude Opus 4.7 (визуальная модель).
- **Figma-партнёрство:** Figma "Code to Canvas" (февраль 2026) конвертирует AI-сгенерированный код в редактируемые Figma-дизайны. Claude Design и Figma Make — параллельные, а не интегрированные продукты.

**Сравнения с конкурентами:**
| Аспект | Claude Design | Figma Make | v0 (Vercel) |
|--------|--------------|------------|-------------|
| Подход | Промпт → прототип | Итерации над существующим файлом | Промпт → код |
| Дизайн-система | Подтягивает из репозитория | Работает с библиотекой Figma | Нет |
| Коллаборация | Ограничена | Полная | Нет |
| Экспорт в Figma | Через html.to.design | Нативно | Нет |
| Фокус | Идеация + мокапы | Production-дизайн | Frontend-код |

**Реакция дизайн-сообщества:** Смешанная. Дизайнеры признают скорость прототипирования, но критикуют ограниченный прямой контроль, высокое потребление токенов и фрейминг "убийца Figma" как завышенный. Консенсус: инструмент для exploration-фазы, не для production-дизайна.

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Token-first подход в Claude Design** — зафиксировать дизайн-токены (цвета, типографика, spacing, радиусы) ДО генерации экранов. Это предотвращает "AI-стиль" в выходе и обеспечивает консистентность. Использовать DESIGN.md как source of truth.

2. **"Onboard once" паттерн** — сначала скормить Claude контекст кодовой базы/дизайн-системы один раз, потом генерировать множество экранов в рамках одной сессии. Критично, потому что сессии не сохраняют память — при новой сессии нужно заново экспортировать и вставить спеки.

3. **Claude Design для exploration, Figma для production** — использовать Claude Design в фазе идеации и быстрой валидации направления, затем переносить в Figma для финальной работы. Не пытаться заменить Figma полностью.

4. ⭐ **ЗАПОМНИТЬ — Claude Design вышел из беты**: С 8 октября доступен на Free-тарифе. Standalone-версия закрывается 14 декабря — нужно перенести дизайн-системы. Для Enterprise включён по умолчанию с 15 октября. Это значит, что инструмент теперь можно тестировать без оплаты и рекомендовать коллегам.

5. ⭐ **ЗАПОМНИТЬ — Требование Claude Code в вакансиях**: На Dribbble появилась вакансия, требующая опыт работы с Claude Code для прототипирования. Навык работы с AI-кодинг-инструментами превращается из "nice-to-have" в требование. Стоит прокачивать.

6. **Слайдеры вместо ре-промптинга** — Claude Design поддерживает интерактивные слайдеры для тонкой настройки (цвет, spacing, типографика). Это быстрее, чем переписывать промпт для каждой микроправки.

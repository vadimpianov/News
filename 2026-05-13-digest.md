### 1. HAIL Framework: human-in-the-loop воркфлоу для продуктовых команд
**Building a human-in-the-loop AI development workflow for modern digital products**
(Построение human-in-the-loop AI-воркфлоу для современных цифровых продуктов)

**Ссылка:** https://techcabal.com/2026/05/12/human-in-the-loop-ai-development-workflow/

**Суть:** Представлен HAIL Framework (Human-Assisted Intelligent Loop) — структурированный подход к интеграции ИИ в продуктовый дизайн и фронтенд-разработку. Ключевая идея: ИИ работает лучше как коллаборация, а не как handoff. Два ключевых этапа: генерация (за час исследуется 5 паттернов взаимодействия вместо одного) и валидация (самый важный слой, который большинство команд пропускает). Человек отвечает за суждения, ИИ ускоряет масштаб и распознавание паттернов.

**Тег:** #продукт #UI #исследование

## AI Design Tool от Anthropic — трекинг

### Статус: Research Preview (запущен 17 апреля 2026)

**Ключевые данные на 13 мая 2026:**

- **Название:** Claude Design (продукт Anthropic Labs)
- **Анонс:** 17 апреля 2026, одновременно с Claude Opus 4.7
- **Доступность:** Research preview для подписчиков Pro, Max, Team, Enterprise на claude.ai/design
- **Движок:** Claude Opus 4.7 — оптимизирован для пространственного восприятия и логики UI/UX
- **Функциональность:**
  - Генерация из текстовых промптов: прототипы, слайды, one-pagers, интерактивные прототипы
  - Чтение кодовой базы и дизайн-файлов для автоматического построения дизайн-системы
  - Захват элементов с живых сайтов
  - Handoff-бандл для Claude Code (React + Tailwind)
  - Конвертация между фреймворками (React → Flutter, Vue)
- **Экспорт:** PDF, PPTX, HTML, Canva, приватный URL
- **Интеграция с Figma:** через Code to Canvas (анонс февраля 2026) — код из Claude конвертируется в редактируемые слои Figma через MCP
- **Ценообразование:** включено в подписки Pro ($20/мес), Max, Team, Enterprise
- **Реакция рынка:** акции Figma упали ~7% после анонса; Adobe, Wix тоже потеряли
- **Конкуренты:** v0 (Vercel), Figma Make, Adobe Firefly, Canva AI
- **Главная критика:** стилистическая однообразность дефолтных генераций (teal-градиенты, одинаковые лейауты)
- **Сильная сторона:** связка Design → Code → Design через Claude Code, чтение реальной кодовой базы

**Новое за 10–12 мая:**
- На Reddit активно обсуждается проблема дефолтного стиля — сообщество требует большей кастомизации
- Mercari (Япония) опубликовали продакшн-кейс после месяца использования
- Claude Platform на AWS стал GA (12 мая) — потенциально упрощает enterprise-внедрение Claude Design

## Выводы

### Что применить в работе дизайнера

1. **4 скилла для Figma-воркфлоу** — подход Sen Lin из UX Collective: Preflight (загрузка Token Map), Design Brief (парсинг задачи), построение по спецификации, проверка результата. Это решает главную проблему — Claude работает вне системы governance Figma, скиллы создают мост.

2. **HAIL Framework** — структурированная коллаборация «человек + ИИ»: генерация (ИИ ускоряет) → валидация (человек проверяет). Критически важный принцип: «валидация — самый важный слой, который большинство команд пропускает».

3. **Борьба с дефолтным стилем Claude Design** — всегда загружать свою дизайн-систему или давать детальные стилистические инструкции. Размытый промпт = одинаковый teal-gradient результат.

4. ⭐ **ЗАПОМНИТЬ — Подход Mercari:** дизайн-диалоги сместились от «как это сделать» к «какой вариант развивать». Цикл Figma → Claude Code → AI-ревью → Figma — это продакшн-подтверждённый воркфлоу крупной компании. Ценно, потому что это не теория, а реальный кейс с конкретным результатом.

5. ⭐ **ЗАПОМНИТЬ — LUI вместо GUI:** китайский ресурс описывает фундаментальный сдвиг — от манипуляции объектами к описанию результата на естественном языке. За 3–5 минут дизайнер получает рабочий прототип. Это меняет не инструмент, а саму логику работы дизайнера.

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Figma AI Agent + Claude Code — двойная интеграция.** Теперь можно использовать Claude Code для генерации UI и отправки в Figma (code-to-canvas), а Figma AI Agent — для работы на холсте через промпты. Два инструмента дополняют друг друга.

2. **Дизайн-система как первый шаг.** Все обзоры подтверждают: загрузка дизайн-системы перед генерацией — разница между generic output и on-brand результатом. Не пропускай этот шаг.

3. **Anti-pattern промпты.** Чтобы избежать «Claude default стиля» (teal-градиенты, serif), прописывай в промптах явные anti-patterns: что НЕ делать, какие стили НЕ использовать.

4. ⭐ **ЗАПОМНИТЬ — Dribbble как структурный референс.** Используй Dribbble-скриншоты не для эстетики, а для композиционной структуры. Скормить Claude лэйаут как структурный гайд — получить прототип за минуты вместо часов. Это меняет сам подход к визуальным референсам.

5. ⭐ **ЗАПОМНИТЬ — Figma AI Agent (20 мая).** Новый ключевой инструмент: AI-агент прямо на холсте Figma, понимающий дизайн-систему и компоненты. Несколько агентов параллельно. Дизайнеры получают «механического помощника» для рутины, оставляя за собой creative direction. Следить за расширением функциональности.

6. **Skill-подход к Claude Code.** Создавай переиспользуемые скиллы под конкретные задачи: один для чтения токенов, другой для аудита, третий для генерации спеков. Четыре узких скилла лучше одного универсального.

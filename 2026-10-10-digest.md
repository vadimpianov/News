## AI Design Tool от Anthropic: трекинг

### Статус на 10 октября 2026

**Продукт:** Claude Design (ранее упоминался как «AI Design Tool»), запущен 17 апреля 2026 как Anthropic Labs research preview.

**Текущий статус:**
- **Вышел из беты** — объявлено 8 октября 2026
- **Enterprise по умолчанию с 15 октября 2026** — админы могут включить раньше
- Standalone-версия (claude.ai/design) закрывается **14 декабря 2026**
- Теперь интегрирован в основной чат Claude, Claude Code, вкладку Artifacts

**Функциональность:**
- Генерация прототипов, слайдов, лендингов, one-pagers из текстовых промптов
- Прямое редактирование на канвасе (drag, resize, align)
- Импорт дизайн-систем (GitHub, файлы, загрузка) с автопроверкой соответствия
- Команда `/design-sync` для подтягивания дизайн-системы
- Связка с Claude Code: хэндофф дизайна в код через одну команду
- Модель: Claude Opus 4.7

**Интеграции:**
- Коннекторы: Adobe, Base44, Canva, Gamma, Lovable, Miro, Replit, Vercel, Wix Headless
- Экспорт: PDF, PPTX, HTML, standalone URL
- **Figma-экспорт: нативного нет.** Figma интеграция идёт через отдельный путь — Figma MCP + Claude Code (Code to Canvas)

**Ценообразование:**
- Включён в подписку Claude Pro, Max, Team, Enterprise
- Использует общий лимит с Claude Code и другими продуктами Claude
- Отдельной цены нет

**Сравнение с конкурентами:**
- **Figma Make** (Claude Sonnet 4 под капотом): генерация прямо в Figma-канвасе, ближе к привычному дизайн-процессу
- **v0 (Vercel)**: генерация React/Tailwind компонентов, фокус на код
- **Lovable**: импорт макета как одноразовый стартер
- Claude Design отличается: читает GitHub-репо и строит дизайн на основе существующего кода и дизайн-системы

**Реакция дизайн-сообщества:**
- 1 миллион пользователей за первую неделю после запуска
- Акции Figma упали на ~12% за две недели после анонса
- Консенсус: для pro-дизайнеров — дополнение, не замена Figma; для PM/разработчиков/фрилансеров — может заменить Figma для quick exploration
- DesignLab запускает платный воркшоп 22 октября — сигнал о растущем образовательном спросе

**Новые продукты (8 октября 2026):**
- **Claude Dashboards** — живые дашборды из данных (BigQuery, Snowflake и др.), beta
- **Claude Motion** — анимированные видео из отчётов и графиков (Team/Enterprise), beta

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Формализуй экспертизу в Skills.** Повторяющиеся дизайн-процессы (аудит доступности, ревью по гайдлайнам, генерация вариантов) стоит оформить как Claude Code Skills — это масштабирует знания одного дизайнера на всю команду. (Источники: UX Isaac, Goodpatch)

2. **Дизайн-система — первый шаг, не последний.** Claude Design даёт лучшие результаты, если дизайн-система загружена до начала работы. Без неё Claude генерирует «узнаваемо-дженерик» стиль. Один час на настройку DS экономит часы итераций. (Источники: Nate Parrott, UISDC, Zhihu)

3. **Генерируй 10 вариантов, выбирай 2, миксуй.** Nate Parrott рекомендует просить 10+ направлений, выбирать сильные и просить Claude комбинировать. Это быстрее, чем итерировать один вариант.

4. **⭐ ЗАПОМНИТЬ: Round-trip Figma ↔ Claude Code — реальный production-воркфлоу.** Несколько авторов независимо описывают один и тот же цикл: Figma → Claude Code (генерация кода) → обратно в Figma (Code to Canvas). Это уже не эксперимент, а рабочий процесс. Стоит попробовать на следующем проекте.

5. **Начинай с вайрфреймов, не с hi-fi.** Когда точность не важна, структура первична — Claude быстрее итерирует на уровне layout, чем на уровне pixel-perfect. (Источник: Nate Parrott)

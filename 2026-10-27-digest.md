## AI Design Tool от Anthropic: трекинг

### Статус: GA на всех планах, standalone закрывается

- **Дата релиза:** 17 апреля 2026 (research preview), доступен на всех планах включая Free с 16 сентября 2026
- **Standalone-версия:** claude.ai/design закрывается 14 декабря 2026. Миграция дизайн-систем доступна. Проекты пока не мигрируются.
- **Функциональность:** генерация прототипов, слайдов, одностраничников через текст; импорт дизайн-систем; /design-sync для синхронизации с кодом; редактор с drag/resize/align; Claude Slides — отдельный формат для презентаций
- **Интеграции:** Claude Code (двусторонняя), Figma (через MCP + Code to Canvas), экспорт в PDF/PPTX/HTML; коннекторы: Adobe, Canva, Gamma, Miro, Replit, Vercel, Wix
- **Ценообразование:** включён во все планы, использует общий лимит; дизайн-системы — только платные планы (бета)
- **Сравнения:** Claude Design vs Figma Make — комплементарны; Claude Design для ранних этапов и смешанных задач, Figma Make для Figma-native прототипирования
- **Реакция сообщества:** смешанная. Дизайнеры ценят скорость генерации, но критикуют лимиты использования, отсутствие прямого Figma-экспорта, ограниченную точность при сложных UI. Японские и китайские ресурсы отмечают трансформацию роли дизайнера в «AI-продюсера».
- **Новинки октября:** Claude Duet (проактивный агент, 21 октября), Claude Haiku 5.5 (7 октября). Дизайн-специфичных обновлений в октябре по данным официальных release notes нет.

## Выводы

### Что применить прямо сейчас

1. **Миграция с standalone Claude Design** — если команда использовала claude.ai/design, нужно до 14 декабря мигрировать дизайн-системы и экспортировать проекты. Чаты и комментарии не переносятся.

2. **Claude Design как инструмент ранних этапов** — инструмент вписывается в начало продуктового цикла: быстрые концепты, питч-деки, одностраничники. Для финальных спеков и production-работы — по-прежнему Figma.

3. **Связка Claude Design → Claude Code** — замкнутый цикл «дизайн → код». Claude Design генерирует прототип, Claude Code конвертирует в production-код. Полезно для дизайнеров, которые хотят валидировать идеи без ожидания разработчика.

4. ⭐ **ЗАПОМНИТЬ — Структурированный ввод для AI-дизайна:** Японские и китайские источники подтверждают: если подать Claude структурированные данные (токены + описания, компоненты + правила, примеры экранов), качество генерации значительно выше, чем при свободном описании. Это применимый приём для любого AI-инструмента дизайна.

5. **Claude Design vs Figma Make** — не «или/или», а «и/и». Claude Design — для исследования и мышления, Figma Make — для построения и тестирования. Оба комплементарны.

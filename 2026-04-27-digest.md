## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Зафиксируй дизайн-систему до начала генерации.** Загрузка палитры, типографики и компонентов в Claude Design (или аналогичный инструмент) в начале сессии резко снижает количество итераций и повышает консистентность выхода.

2. **Claude Design = первые 80%, Figma = финальные 20%.** Используй AI для быстрой идеации, структурных черновиков и внутренних ревью. Переключайся на Figma для pixel-perfect продакшна. Это не замена, а конвейер.

3. **Боритесь с «AI-видом».** Настройка DESIGN.md / Claude Skills с конкретными стилевыми ограничениями (запрет на дефолтные градиенты, указание конкретных шрифтов) позволяет генерировать UI, который не выглядит шаблонным.

4. **Inline-комментарии вместо переописания.** При итерациях в Claude Design эффективнее указывать на конкретный элемент с замечанием, чем описывать всю правку текстом — экономит токены и повышает точность.

5. **⭐ ЗАПОМНИТЬ: Итерируй живьём с инженерами.** Claude Design генерирует макеты достаточно быстро, чтобы прототипировать прямо на совместной сессии с разработчиком. Это убирает async-петлю «бриф → макет → ревью → правки» и сжимает недельный цикл до одного дня. Ценная идея, потому что меняет процесс, а не просто инструмент.

6. **⭐ ЗАПОМНИТЬ: Полный цикл Claude Design → Figma MCP → Claude Code.** Структура Planner-Generator-Evaluator (дизайн → код → ревью человеком) — рабочая модель, которая масштабируется. Дизайнер остаётся Evaluator-ом, а не оператором.

## Выводы

### Приёмы, которые можно применить в работе дизайнера:

1. **Claude Design для ideation, Figma для системной работы.** Консенсус из множества источников: Claude Design выигрывает на этапе первого драфта и быстрой итерации. Figma остаётся незаменимой для зрелых компонентных систем и коллаборации.

2. ⭐ **ЗАПОМНИТЬ: Design Skills как markdown-файлы.** Marie Claire Dean показала, что 63 структурированных скилла в markdown позволяют Claude работать по фреймворкам опытного дизайнера (персоны, аудит дизайн-систем, хендофф). Это конкретный, воспроизводимый подход: создаёте свои скиллы → Claude работает по вашей методологии. Это даёт дизайнеру контроль над тем, КАК AI дизайнит, а не просто ЧТО.

3. ⭐ **ЗАПОМНИТЬ: Двусторонний Figma ↔ Code воркфлоу.** Figma "Code to Canvas" + Claude Code позволяет захватывать работающий UI из браузера и конвертировать в редактируемые фреймы, а затем push изменений обратно в код. Это убирает «последнюю милю» между дизайном и реализацией.

4. **Наличие дизайн-системы критично.** Reddit-дискуссия показала: без готовой дизайн-системы результат Claude Design слабый. С готовой системой — результат резко лучше. Инвестиции в дизайн-систему окупаются вдвойне в эпоху AI.

5. **Роль дизайнера трансформируется: от исполнителя к «AI-продюсеру».** Японские и западные источники сходятся: ценность смещается от навыков исполнения (пикселей) к стратегическому мышлению, управлению AI и умению формулировать дизайн-намерение.

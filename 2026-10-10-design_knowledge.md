# Предложенные дизайн-принципы — 2026-10-10

> Ожидают одобрения дизайнера. НЕ записаны в design_knowledge.md.

---

## 1. Figma-техники

- **Принцип:** Используй итеративный подход «проходами» при генерации через AI: сначала layout и IA, затем типографика и spacing, потом цвет, последним — микро-интеракции.
- **Почему:** Каждый проход фиксирует один слой решений, AI не путает структуру с декором, а ревью каждого прохода проще. При попытке генерировать всё за один промпт качество падает.
- **Источник:** [把 Claude Design 做成 Skill — Zhihu](https://zhuanlan.zhihu.com/p/2030368442012917806)
- **Дата:** 2026-10-10

---

## 2. Компоненты & Паттерны

- **Принцип:** Формализуй повторяющиеся дизайн-ревью (аудит доступности, проверка по гайдлайнам, Нильсен-эвристики) в переиспользуемые Skills/инструкции — это превращает экспертизу дизайнера в актив команды.
- **Почему:** Знания одного senior-дизайнера масштабируются на команду без потери качества. Junior-дизайнеры и разработчики получают тот же уровень ревью при каждом запуске, а не только когда senior доступен.
- **Источник:** [How I Turn My UX Design Workflow Into Claude Code Skills — UX Isaac](https://www.uxisaac.com/blog/claude-code-skills-ux-design-workflow) + [Goodpatch Blog](https://goodpatch.com/blog/2026-05-design-workflow)
- **Дата:** 2026-10-10

---

## 3. Анти-паттерны

- **Принцип:** Не запускай AI-генерацию дизайна без предварительно загруженной дизайн-системы — результат будет «узнаваемо-дженерик» и потребует полной переделки вместо доработки.
- **Почему:** Claude Design (и аналоги) без DS изобретают собственный визуальный язык, который выглядит чисто, но не соответствует бренду. Час на настройку DS до генерации экономит часы ручных правок после.
- **Источник:** [How the product designer who built Claude Design uses it — Claude Blog](https://claude.com/blog/how-the-product-designer-who-built-claude-design-uses-it-to-explore-ideas-before-building-them) + [Claude Design: Setting Up Your Own Brand Design System — Markus Stoeger](https://markusstoeger.com/en/masterai/claude-design-uebung-3-design-system)
- **Дата:** 2026-10-10

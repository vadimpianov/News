## AI Design Tool от Anthropic: трекинг

### Статус на 2 ноября 2026

| Параметр | Данные |
|---|---|
| **Название** | Claude Design (ранее — отдельный продукт Anthropic Labs) |
| **Дата запуска** | 17 апреля 2026 (research preview) |
| **Выход из беты** | ~8 октября 2026 (по данным третьих источников, не подтверждено Anthropic официально) |
| **Модель** | Claude Opus 4.7 |
| **Доступность** | Free, Pro, Max, Ultra, Team, Enterprise |
| **Standalone-версия** | claude.ai/design — закрывается 14 декабря 2026, после чего read-only |
| **Интеграция в Claude** | С 16 сентября 2026 — дизайн как тип артефакта в основном интерфейсе |
| **Enterprise** | Включён по умолчанию с 15 октября 2026 |

### Функциональность
- Создание интерактивных прототипов, лендингов, слайд-деков, маркетинговых материалов из текстовых описаний
- Импорт дизайн-систем из GitHub, файлов дизайна, ручной загрузки
- Прямое редактирование на canvas (drag, resize, align, edit text, change colors)
- Inline-комментарии и голосовой ввод
- Экспорт в PDF, PowerPoint, HTML
- Коннекторы: Canva, Gamma, Miro, Vercel, Replit, Lovable, Wix, Adobe, Base44

### Интеграции с Figma
- **Figma "Code to Canvas" (февраль 2026):** конвертация кода из Claude Code в редактируемые слои Figma
- **Нативного экспорта из Claude Design в Figma нет** — используются сторонние инструменты (html.to.design, Anima)
- **Figma MCP Server:** позволяет Claude Code читать Figma-файлы напрямую
- **Напряжение:** запуск Claude Design вызвал падение акций Figma на 6-7.7%

### Ценообразование
- Входит в подписку Claude (Pro — $20/мес, Max — от $100/мес, Team — $30/мес за пользователя)
- Общий пул лимитов с Claude Code и чатом (ранее был отдельный недельный лимит)

### Сравнение с конкурентами
- **vs Figma:** Claude Design для идеации и ранних прототипов; Figma — для production-дизайна, компонентных библиотек, командной работы, dev handoff
- **vs Canva:** Anthropic позиционирует Claude Design как дополнение к Canva (есть двухлетнее партнёрство с Canva)
- **vs v0 (Vercel):** Claude Design генерирует полноценные интерактивные прототипы, v0 фокусируется на компонентах

### Реакция дизайн-сообщества
- Дизайнеры признают полезность для ранних этапов, но не для production
- Основная критика: отсутствие истории версий, нет прямого экспорта в Figma
- Хвалят: скорость генерации вариантов, поддержку дизайн-систем, синхронизацию с Claude Code

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Загружайте бренд-ассеты ДО начала работы с Claude.** Реальный лендинг или питч-дек передаёт ощущение бренда лучше, чем абстрактный файл с токенами. Это предотвращает генеричность результата.

2. **Запрашивайте 10+ вариантов, затем микшируйте лучшие.** Техника Нейта Пэрротта: попросить Claude сделать десяток вариантов, затем выбрать 2-3 и попросить скомбинировать их сильные стороны.

3. **Используйте `/design-sync` в Claude Code** для подтягивания дизайн-системы из проекта. Это гарантирует, что новые дизайны стартуют с существующих компонентов.

4. **Переходите в Claude Code после фиксации макета.** Итерации визуального дизайна в Claude Design дороже по токенам, чем доработка в Code.

5. **Прямое редактирование (drag, resize, colors) не тратит токены.** Финальные правки лучше делать руками в canvas-редакторе Claude Design.

6. ⭐ **ЗАПОМНИТЬ: Диктуйте комментарии вместо длинных текстовых описаний.** Нейт Пэрротт рекомендует кликнуть на элемент и наговорить комментарий голосом. Это быстрее, точнее и естественнее, чем писать промпт. Полезно для дизайнеров, которым проще объяснить словами, чем формулировать текст.

7. ⭐ **ЗАПОМНИТЬ: Настройка CLAUDE.md проекта — ключ к консистентности.** Вместо повторения стилевых инструкций в каждом промпте, зафиксируйте бренд, типографику, spacing и правила компонентов в файле проекта. Claude будет применять их автоматически.

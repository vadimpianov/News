## AI Design Tool от Anthropic (Claude Design) — Отдельный трекинг

### Статус продукта
- **Дата анонса:** 17 апреля 2026
- **Статус:** Research Preview (не GA)
- **Доступность:** Claude Pro, Max, Team, Enterprise

### Функциональность
- Генерация прототипов, слайдов, лендингов, one-pagers из текстовых промптов
- Onboarding: Claude читает кодовую базу и дизайн-файлы, строит дизайн-систему (цвета, типографика, компоненты), автоматически применяет ко всем последующим проектам
- Интерактивные прототипы с анимациями, voice, video, 3D, шейдерами
- Live canvas с итеративной доработкой через чат, инлайн-комментарии, прямое редактирование
- Web capture tool — захват элементов с живого сайта для прототипов

### Интеграции
- **Экспорт:** PDF, PPTX, HTML, URL, Canva (полностью редактируемый)
- **Figma:** Нативной интеграции НЕТ. Figma выпустила отдельный «Code to Canvas» (февраль 2026) для конвертации кода из Claude Code → Figma. Но Claude Design → Figma напрямую невозможно.
- **Claude Code:** Handoff «ready to build» работает
- **Creative Connectors (май 2026):** Adobe, Blender, Ableton, Affinity by Canva, Autodesk Fusion

### Ценообразование
- Входит в подписки Pro, Max, Team, Enterprise
- Pro лимитов не хватает для регулярной дизайн-работы
- Max 20x — минимум для продуктивного использования

### Сравнения с конкурентами
- **vs Figma:** Claude Design — для быстрого exploration и прототипирования; Figma — для production UI. Не взаимозаменяемы. Акции Figma упали на 7% после анонса.
- **vs v0 (Vercel):** Claude Design генерирует более широкий спектр визуального контента (не только UI)
- **vs Canva:** Прямая интеграция; Claude Design как генератор → Canva как редактор
- **vs Adobe Firefly:** Разные ниши; Anthropic добавила Adobe connector

### Реакция дизайн-сообщества
- Якоб Нильсен: инструмент полезен, но нет UX-research фич
- Reddit/HN: смешанные отзывы; хорош для non-designers и быстрого прототипирования, профессиональные дизайнеры отмечают отсутствие моста к Figma
- Дизайнеры из Brilliant: «step change» — 20+ промптов в других инструментах = 2 промпта в Claude Design
- Datadog: время от идеи до прототипа — с недели до одного разговора

### Обновления за май 2026
- Добавлены Creative Connectors (Adobe, Blender, Ableton, Affinity, Autodesk Fusion)
- Claude Opus 4.7 GA — улучшенный vision для более точного дизайна
- Managed Agents — для длительных дизайн-сессий

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Design System First подход:** Перед началом работы в Claude Design загрузите свою дизайн-систему (бренд-гайд, токены, палитру). Claude автоматически применит её ко всем генерируемым проектам — это убирает «AI-generic look».

2. **Один шрифт, уверенно:** Вместо абстрактных промптов задавайте Claude Design жёсткие ограничения: конкретный шрифт, доминирующий цвет, стиль. Это даёт более профессиональный результат, чем «сделай красиво».

3. **Пайплайн Claude Design → Canva → Claude Code:** Для стартапов и маленьких команд: визуальная генерация → коллаборативная доработка → имплементация. Весь процесс на естественном языке.

4. ⭐ **ЗАПОМНИТЬ: Дизайнер как оператор, а не рисовальщик.** Роль UX-дизайнера смещается от ручного создания к определению «Design DNA» (токены, правила spacing, паттерны) и стратегическому контролю. AI генерирует варианты, дизайнер принимает решения. Это не «замена дизайнера», а эволюция роли — от craft к operation. Важно освоить этот переход сейчас.

5. ⭐ **ЗАПОМНИТЬ: Кейс Brilliant — 20 промптов → 2 промпта.** Показывает, что правильно структурированная дизайн-система + чёткие ограничения в промпте = драматическое сокращение итераций. Это применимо к любому AI-дизайн-инструменту.

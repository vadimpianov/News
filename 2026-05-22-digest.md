## Выводы

### Что применить прямо сейчас

1. **Figma AI Agent (бета)** — ⭐ **ЗАПОМНИТЬ**. Figma запустила нативного AI-агента. Для дизайнеров: можно давать команды на естественном языке, запускать несколько агентов параллельно, автоматизировать рутину прямо на канвасе. Следить за раскаткой бета-версии — в бета-период кредиты не расходуются.

2. **Design System = Source of Truth для AI**. Главный паттерн мая: без загруженной дизайн-системы любой AI-инструмент выдаёт generic «AI slop». Токены (цвета, типографика, spacing, radius) должны быть зафиксированы ДО начала работы с Claude Design / Figma AI / любым генеративным инструментом.

3. **Negative constraints** — говорить AI чего НЕ делать («не используй градиенты», «не делай rounded corners > 8px») убирает дефолтные AI-паттерны и даёт более уникальный результат.

4. **Claude Design → Claude Code pipeline** — полный цикл от идеи до продакшн-кода в одной экосистеме. Если вы уже используете Claude, это снижает потери при handoff.

5. ⭐ **ЗАПОМНИТЬ — Двусторонний поток Figma ↔ Claude**. Теперь работает в обе стороны: код → Figma (Code to Canvas) и Figma → код (Claude Code + MCP). Дизайнер может работать в привычной среде, а AI-инструменты обеспечивают мост. Это меняет workflow: не «дизайн ИЛИ код», а «дизайн И код как единая среда».

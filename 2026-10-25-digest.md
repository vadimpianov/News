**Функциональность:**

- Дизайн-системы: загрузка из кодовой базы, Figma, бренд-деков, PDF
- Экспорт: PDF, PPTX, HTML, Canva
- Интеграция с Claude Code: двусторонняя синхронизация (дизайн ↔ код)

**Новое в октябре 2026:**
- Claude Dashboards (живые дашборды с данными из BigQuery, Snowflake, Databricks, Redshift, ClickHouse, Salesforce)
- Claude Motion (анимированные эксплейнеры, моушн-графика — код, не генеративное видео)

- Code to Canvas (февраль 2026): конвертация кода из Claude Code в редактируемые фреймы Figma
- Нативного экспорта из Claude Design в Figma нет — обходной путь через Claude Code + Figma MCP
- В апреле 2026 стоимость акций Figma упала после запуска Claude Design

**Конкуренты:**
- Figma AI / Figma Make — нативная среда, но сильнее в векторной работе и version history
- v0 (Vercel) — генерация UI-компонентов из промптов
- Adobe Firefly — фокус на графике и изображениях, не на прототипировании
- Canva AI — упрощённая генерация маркетинговых материалов

**Ценообразование:** Claude Design доступен бесплатно на Free-тарифе. На платных тарифах (Pro, Max, Team, Enterprise) доступна вся функциональность включая дизайн-системы и Motion.

**Реакция сообщества:** Дизайнеры отмечают полезность для быстрого прототипирования и «первого экрана», но подчёркивают необходимость ручной доработки. Моушн-дизайнеры рассматривают Motion как угрозу для шаблонных проектов, но не для креативной режиссуры.

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **DESIGN.md как фундамент** — перед любой работой с Claude зафиксировать дизайн-токены, правила типографики, палитру и отступы в DESIGN.md. Это главная причина «генеричного» результата AI — размытые входные данные. Конкретный файл с обоснованием решений даёт Claude контекст для обработки крайних случаев.

2. **Инлайн-комментарии вместо пересоздания** — вместо переделки всего экрана, оставлять точечные комментарии к конкретным элементам (кнопке, карточке, секции). Claude Design обрабатывает их точнее, чем общие запросы.

3. **Разделение ролей: Claude Design → Figma → код** — Claude Design для быстрой генерации первого варианта, Figma для точной доработки и системной работы, Claude Code для реализации. Не пытаться сделать всё в одном инструменте.

4. ⭐ **ЗАПОМНИТЬ — CLAUDE.md для дизайн-систем**: Хранить дизайн-токены и стандарты компонентов в CLAUDE.md проекта, чтобы Claude Code генерировал консистентный код без повторных объяснений. Это масштабируемый подход для команд — правила пишутся один раз и работают для всех участников.

5. ⭐ **ЗАПОМНИТЬ — Claude Motion для рутинных видео**: Claude Motion пишет анимацию как код — текст, числа, тайминги редактируемы. Подходит для регулярных эксплейнеров (рекапы, прайсинг, онбординг). Дизайнер сохраняет роль режиссёра: выбор акцентов и ритм остаются человеческой задачей.

## 1. Анти-паттерны

**Принцип:** AI-генерированный UI имеет узнаваемые «слоповые» маркеры — фиолетовые градиенты, glassmorphism по умолчанию, робкая типографика (мелкий размер, низкий контраст), избыточные скругления — которые нужно явно запрещать в промптах или через skill-конфигурацию.

**Почему:** Taste Skill v2.0.0 и Notion UX/UI Skills построены вокруг борьбы именно с этими дефолтами. Если не контролировать — любой AI-сгенерированный интерфейс выглядит одинаково и «по-ботовому», что снижает доверие пользователей.

**Источник:** [Skillselion — Claude Design Skills](https://skillselion.com/design), [Notion UX/UI Design Skills](https://yummy-design.notion.site/Claude-UX-UI-Design-Skills-31462791470981a99fe1c993b08c5347)

**Дата:** 2026-10-20

## 2. Компоненты & Паттерны

**Принцип:** При работе с AI-генерацией UI эффективнее итерировать послойно: сначала информационная архитектура и лейаут, затем типографика и spacing, затем цвет и визуальная иерархия, затем микроинтеракции — а не пытаться получить финальный результат за один промпт.

**Почему:** Этот паттерн описан в нескольких источниках как стандартный воркфлоу Claude Design. Послойный подход даёт больше контроля и предсказуемости: каждый слой можно оценить и скорректировать отдельно, а ошибки не каскадируются.

**Источник:** [What Is Claude Design? The 2026 Guide](https://aiireland.ie/2026/04/22/what-is-claude-design-the-2026-guide-to-ai-powered-ui-prototyping-creative-workflows/)

**Дата:** 2026-10-20

## 3. Figma-техники

**Принцип:** Дизайн-систему в Figma можно генерировать быстрее через Claude, если сначала попросить создать наборы токенов (цвет, типографика, spacing, radius) в формате Figma Variables, а затем использовать их как основу для компонентов — вместо создания каждой переменной вручную.

**Почему:** Ручное создание переменных — одна из самых рутинных задач в Figma. Генерация токенов через Claude + импорт через MCP или Variables API сокращает setup дизайн-системы с часов до минут. Кейс из Design Systems Collective: полная дизайн-система за 15 минут.

**Источник:** [How I Built a Design System in 15mins](https://www.designsystemscollective.com/no-64-figma-mcp-claude-code-3-how-i-built-a-design-system-in-15mins-6ef95145a4e5)

**Дата:** 2026-10-20

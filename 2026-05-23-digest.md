### Figma Make vs Claude Design: какой AI-инструмент лучше? (май 2026)

## AI Design Tool от Anthropic: трекинг

### Статус: Research Preview (запущен 17 апреля 2026)

**Что нового за 18–22 мая:**

1. **Удвоение лимитов (18 мая)** — месячные токены удвоены на всех планах без повышения цены. Это снимает ключевой барьер: раньше setup дизайн-системы мог израсходовать весь недельный лимит Pro-плана.

2. **Code with Claude London (19–21 мая)** — на конференции Claude Design упоминался в контексте end-to-end пайплайна: идея → Claude Design (прототип) → Claude Code (код) → production. Появилось направление «Claude Code for Designers».

3. **Figma ответила запуском Design Agent (20 мая)** — нативный AI-агент прямо в канвасе Figma. Бесплатно в бете. Это прямой ответ на Claude Design — Figma показывает, что AI-дизайн будет жить внутри их платформы, а не в стороннем инструменте.

**Текущие характеристики Claude Design:**
- **Движок:** Claude Opus 4.7
- **Доступность:** Research Preview — Pro ($20/мес), Max, Team, Enterprise
- **Функциональность:** генерация прототипов, слайдов, лендингов, маркетинговых one-pager'ов из текстовых промптов; рефайн через разговор, инлайн-комменты, слайдеры; чтение кодовой базы и Figma-файлов для автоматического построения дизайн-системы
- **Экспорт:** PDF, PPTX, HTML; передача в Canva и Claude Code
- **Интеграции с Figma:** двусторонний обмен через MCP (Code to Canvas), но прямого Figma-экспорта из Claude Design пока нет
- **Ценообразование:** включено в подписку Claude, без отдельной платы; лимиты зависят от плана
- **Ограничения:** нет прямого перемещения элементов на канвасе (только через промпт); fidelity дизайн-системы ~50-75%; не подходит для production-дизайна в команде
- **Конкуренты:** Figma Make (нативные прототипы), Figma Design Agent (нативный AI в канвасе), v0/Lovable (code-gen), Adobe Firefly

**Реакция рынка:**
- Акции Figma упали на 7% в день запуска Claude Design, но Figma подняла годовой прогноз после Q1 с выручкой $333.4M (+46%)
- Профессиональные дизайнеры: «не убийца Figma — комплементарный инструмент для идеации»
- PM/фаундеры/разработчики: «реальная альтернатива для быстрых визуалов без Figma»

## Выводы

### Что применить прямо сейчас

1. **Figma Design Agent** — ⭐ **ЗАПОМНИТЬ**. Бесплатная бета, доступна сейчас. Попробовать для: массовых обновлений библиотеки (документирование компонентов, стандартизация нейминга), суммирования фидбэка, конвертации экранов в dark mode. Агент «знает» ваш файл — не нужно описывать контекст.

2. **Правило «Library First» для Claude Code** — ⭐ **ЗАПОМНИТЬ**. Из статьи Sen Lin: каждая задача по построению UI начинается с поиска в подключённой библиотеке. Если компонент найден — используй instance. Hex-цвета автоматически конвертируются в семантические токены. Это предотвращает дрифт дизайн-системы при работе с AI.

3. **Skills для борьбы с «AI-шной» эстетикой** — создать frontend-design Skill с вашими дизайн-спецификациями, чтобы Claude генерировал UI в стиле вашей команды, а не в дефолтном. Hexabase и Zhihu описывают конкретные подходы.

4. **Двусторонний Figma-Claude пайплайн** — Mercari показывает зрелый процесс: Figma → Claude Code → AI-ревью → код → обратно в Figma. Пять шагов вместо традиционного waterfall.

5. **Роль дизайнера разделяется** — производство (компоновка, варианты, контент) автоматизируется; суждение (что строить, зачем, когда нарушить паттерн) остаётся за человеком. Инвестировать в навыки суждения, исследования и стратегии.

## 1. Skills-файл как design system guard

**Категория:** Компоненты & Паттерны / Figma-техники

**Принцип:** Фиксировать правила дизайн-системы (тон, типографика, спейсинг, палитра, компоненты) в skills-файле для AI-инструмента, а не полагаться на ad hoc промпты — это обеспечивает автоматическую проверку каждого вывода на соответствие гайдлайнам.

**Почему:** При генерации UI через AI без строгих правил результат выглядит «AI-шно» и generic; skills-файл превращает AI в «компетентного дизайнера компании», который знает и соблюдает design system, что масштабируется лучше, чем ручная проверка каждого экрана.

**Источник:** [Hexabase — 脱「AIっぽい」デザイン！Claude Skills для профессионального UI](https://www.hexabase.com/column/ai-design-claude-skills-workflow)

**Дата:** 2026-11-05

## 2. Context-first подход к генерации: сначала конкуренты, потом прототип

**Категория:** Компоненты & Паттерны

**Принцип:** Перед генерацией прототипа через AI сначала загрузить в контекст 3–5 конкурентных сайтов/приложений — AI использует их паттерны, структуру и conventions как основу, а не генерирует «из головы».

**Почему:** Абстрактный промпт типа «сделай лендинг для SaaS» даёт generic результат; промпт с контекстом реальных конкурентов даёт результат, который учитывает conventions индустрии, ожидания пользователей и конкурентное позиционирование — то, что дизайнер обычно собирает на этапе research.

**Источник:** [Medium/Design Bootcamp — Design with context: A Claude skill that studies competitors](https://medium.com/design-bootcamp/design-with-context-a-claude-skill-that-studies-competitors-and-builds-your-prototype-e4cdd8cb7519)

**Дата:** 2026-11-05

## 3. Dev-mode CSS как промпт-контекст для точности code generation

**Категория:** Figma-техники

**Принцип:** При генерации кода из Figma-дизайна через MCP добавлять к промпту CSS-спецификации из Figma dev-mode (конкретные значения padding, margin, font-size, border-radius) — это повышает точность попадания AI в pixel-perfect результат.

**Почему:** MCP передаёт структуру компонентов и токены, но не всегда точные CSS-значения; добавление dev-mode CSS закрывает этот gap и снижает количество итераций исправлений с 5–7 до 1–2.

**Источник:** [Eleken — Figma to Claude Code: Real Workflow, Use Cases & Limitations](https://www.eleken.co/blog-posts/figma-to-claude-code)

**Дата:** 2026-11-05

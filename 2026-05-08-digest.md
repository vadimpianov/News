## AI Design Tool от Anthropic — трекинг

### Статус: Research Preview (доступен)

**Дата релиза:** 17 апреля 2026 — запуск Claude Design как research preview.

**Доступность:** Постепенный rollout для подписчиков Pro, Max, Team, Enterprise. Включён в существующую подписку без доплаты (расходует отдельные лимиты).

**Функциональность:**
- Генерация прототипов, слайд-деков, лендингов, one-pagers через диалог
- Powered by Claude Opus 4.7 с улучшенным визуальным восприятием (до 2576px)
- Вывод: live HTML/CSS/React+Tailwind (не статичные картинки)
- 3 вариации дизайна на выходе
- Inline-комментарии, ручное редактирование текста, кастомные слайдеры
- Handoff Bundle: экспорт React-логики и Tailwind-классов для разработки
- Экспорт в PDF, PPTX, URL, Canva

**Интеграции:**
- **Figma**: двусторонняя — через «Code to Canvas» (код → Figma) и MCP (Figma → код)
- **Adobe Creative Cloud**: коннектор (28 апреля) — 50+ инструментов, Photoshop, Premiere, Express
- **Blender**: коннектор с Python API, Anthropic — Corporate Patron Blender Development Fund (€240K+/год)
- **Ableton, Affinity, Autodesk Fusion**: коннекторы (28 апреля)
- Word/PowerPoint: возможность использовать как входные данные

**Ценообразование:**
- Включён в подписки Pro ($20/мес), Max ($100/$200/мес), Team, Enterprise
- Отдельные лимиты от чата и Claude Code
- На Code with Claude SF (6 мая) лимиты удвоены

**Сравнение с конкурентами:**
- Акции Figma упали на 7% в день запуска Claude Design
- Майк Кригер (CPO Anthropic, бывший Figma) покинул совет директоров Figma 14 апреля
- Lenny's Newsletter: Claude Design выигрывает в ideation и первых драфтах; Figma — в командной коллаборации, handoff и глубине экосистемы
- Reddit: «Умный воркфлоу — Claude Design И Figma, а не Claude Design ИЛИ Figma»
- Usage limits — главная реальная проблема (#1 friction по отзывам)

**Реакция дизайн-сообщества:**

## Выводы

### Что применить прямо сейчас

1. **Удвоенные лимиты Claude Code/Design** (с 6 мая) — больше пространства для итераций. Если раньше экономили токены, можно пробовать более амбициозные прототипы.

2. **Коннекторы Adobe + Blender + Affinity** (с 28 апреля) — Claude теперь работает с файлами Photoshop, Premiere, Blender напрямую. Для мультидисциплинарных дизайнеров это означает единый ИИ-хаб для всех инструментов.

3. ⭐ **ЗАПОМНИТЬ — Двусторонний воркфлоу Claude ↔ Figma (опыт Mercari):** Claude Code как хаб для прототипирования → сбор фидбека → запись в Figma как финальный дизайн. Это инвертирует привычный процесс: Figma подключается позже, а не раньше. Полезно для команд, где скорость итераций важнее визуальной точности на ранних этапах.

4. ⭐ **ЗАПОМНИТЬ — Подход Jane Street:** дизайнер прототипирует напрямую в Claude Code, пропуская Figma для некоторых проектов. Расширяет возможности дизайнера — можно самостоятельно создавать proof of concept без инженеров. Особенно ценно для внутренних инструментов и дашбордов.

5. **Claude Design лучше всего для:** маркетинговых лендингов, слайд-деков и креативных редизайнов (по Lenny's Newsletter). Для сложных продуктовых интерфейсов с дизайн-системой пока ограничен — генерирует «похожие» компоненты вместо точных.

6. **Роль дизайнера сдвигается** от craft к decision-making: выбор что строить, оценка качества AI-вывода, курирование вариантов. Это тема статьи UX.raspberry и перекликается с идеями Jenny Wen.

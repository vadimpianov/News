- **Вышел из беты:** по данным одного обзора, 8 октября 2026 (требует проверки по официальным источникам)
- **Доступность:** Pro, Max, Team, Enterprise (Enterprise — активация администратором)
- **Ценообразование:** входит в подписку Claude, с отдельной еженедельной квотой на Design. Enterprise — кастомное ценообразование
- **Функциональность:**
  - Генерация UI/прототипов/слайдов/маркетинговых материалов из промптов
  - Автоматическое извлечение дизайн-системы из кодовой базы (палитра, шрифты, компоненты)
  - Бидирекциональная синхронизация с Claude Code
  - Бренд-контроли для Enterprise (администратор задаёт дизайн-систему, ограничивает правки)
  - Команда `/design` в Claude Code
- **Ограничения:**
  - Нет нативного импорта/экспорта Figma (нужен html.to.design или подобный инструмент)
  - Нет панели слоёв и пиксельного редактирования
  - Квота расходуется быстро, особенно при ingestion кодовой базы
  - Нет аудит-логов использования
  - Не поддерживает требования data residency
- **Интеграции:**
  - Figma: через html.to.design (browser extension + MCP коннектор), через Code to Canvas (Figma + Anthropic partnership, февраль 2026)
  - Claude Code: прямая передача через Export → Handoff

- **Конкуренция:**
  - Figma Make: использует Claude Sonnet 4 для генерации дизайна внутри Figma

  - Adobe Firefly: AI для визуального контента
  - UXPilot, Magic Patterns: альтернативные AI-инструменты для прототипирования
- **Реакция сообщества:**
  - Позитив: быстрая генерация первых драфтов, автоизвлечение дизайн-системы, интеграция с кодом

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Claude Design как слой в чате** — после слияния в сентябре 2026 дизайн стал доступен в любом разговоре с Claude. Не нужно переключаться между инструментами: формулируй контекст в чате, затем переходи к визуальной генерации в той же сессии.

2. **Загружай дизайн-систему ДО промптинга** — все обзоры сходятся: без загруженной дизайн-системы результат будет «красивым, но безликим». С ней — Claude генерирует в бренде. Для Enterprise это теперь контролируется администратором.

3. **Мелкие правки — в Figma, не в промптах** — практики показывают, что перепромпчивание мелких деталей расходует токены и рискует сломать другие части макета. Финальная полировка быстрее в Figma.

4. ⭐ **ЗАПОМНИТЬ — Разделяй дизайн и код**: не пытайся дизайнить и кодить в одном разговоре. Claude Design — для визуальной разведки, Claude Code — для продакшена. Handoff между ними — через Export → Handoff to Claude Code. Это ключевой вывод из практических обзоров октября 2026.

5. **Skills как постоянный бриф** — вместо повторения контекста в каждом промпте используй Claude Skills для дизайна (Figma Resource Library описывает 10 навыков). Один раз настроил — Claude всегда знает твои правила.

6. **Просить несколько вариантов** — просить 3–4 направления для одного блока быстрее, чем угадывать правильное с одной попытки.

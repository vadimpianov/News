## 1. Компоненты & Паттерны

- **Принцип:** При проектировании с AI описывай сначала весь user flow целиком, а потом детализируй отдельные экраны в контексте этого flow — результат будет связным, а не набором разрозненных экранов.
- **Почему:** AI без контекста flow оптимизирует каждый экран локально, теряя переходы, состояния и edge cases между шагами. Трёхшаговый подход (flow → экраны → связки) устраняет эту проблему.
- **Источник:** [Claude Design for UX: How to Design Complete User Flows](https://uxplanet.org/claude-design-for-ux-how-to-design-complete-user-flows-not-just-ui-screens-094d6b8a7855)
- **Дата:** 2026-10-26

---

## 2. Figma-техники

- **Принцип:** Импортируй дизайн-систему в AI-инструмент через `/design-sync` до начала работы — AI будет валидировать каждый output против твоих токенов и компонентов автоматически.
- **Почему:** Без импорта AI генерирует "generic" UI с системными шрифтами и стандартными цветами, а потом дизайнер тратит время на ручное приведение к бренду. С импортом корректировка происходит до показа результата.
- **Источник:** [Claude Design now stays on brand for daily work](https://claude.com/blog/claude-design-stays-on-brand-for-daily-work)
- **Дата:** 2026-10-26

## 3. Анти-паттерны

- **Принцип:** Не устанавливай все AI design skills одновременно — разделяй ответственность: один для design direction, другой для visual quality, третий для accessibility checks.
- **Почему:** Конфликтующие инструкции из нескольких скиллов создают непредсказуемый "AI slop" — несогласованные стили, нестабильные результаты между запросами. Модульный подход даёт контроль над каждым аспектом.
- **Источник:** [The 20 Best Claude Code Skills for UI/UX Design](https://pasqualepillitteri.it/en/news/576/claude-code-skills-design-uiux-guide)
- **Дата:** 2026-10-26

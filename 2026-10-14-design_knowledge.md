## 1. Компоненты & Паттерны

**Принцип:** Определяй tone & manner, правила компонентов и accessibility-требования в отдельном файле (skill.md), чтобы AI-генерация UI давала результат, неотличимый от ручной работы.

**Почему:** Без явных правил AI-инструменты (Claude Design, Claude Code) генерируют «типичный AI-look» — одинаковые макеты с предсказуемой сеткой, дефолтной типографикой и шаблонными цветами. Skill-файл с конкретными ограничениями (размеры, отступы, палитра, тон текста) заставляет AI соблюдать brand identity.

**Источник:** [脱「AIっぽい」デザイン！Claude Skillsで実現する、プロ仕様のUI自動生成ワークフロー](https://www.hexabase.com/column/ai-design-claude-skills-workflow) — Hexabase (Япония)

**Дата:** 2026-10-14

## 2. Spacing & Layout

**Принцип:** Итерируй дизайн по слоям в фиксированном порядке: информационная архитектура и лейаут → типографика и spacing → цветовая иерархия → микроинтеракции — никогда не пытайся определить всё за один проход.

**Почему:** При работе с AI-инструментами (и вручную) попытка описать всё сразу даёт размытый результат. Послойная итерация позволяет на каждом шаге фокусироваться на одном аспекте и получать контролируемые улучшения. Этот подход подтверждён несколькими независимыми источниками, включая внутренних дизайнеров Anthropic.

**Источник:** [Claude Design for UI UX: how to get the best design output](https://medium.com/@motionlabs26/claude-design-for-ui-ux-how-to-get-the-best-design-output-for-content-creation-c595db7b59e0) — MotionLabs, Medium + [Claude Design 完全指南](https://rar.design/posts/claude-design-complete-guide) — RAR Design

**Дата:** 2026-10-14

## 3. Figma-техники

**Принцип:** Сгенерируй правила дизайн-системы один раз через Claude Code + Figma MCP (команда `create_design_system_rules`), сохрани файл в проекте — все дальнейшие сессии Claude Code будут автоматически соблюдать токены, компоненты и spacing.

**Почему:** Без персистентных правил каждая новая сессия Claude Code начинает «с нуля» и может сгенерировать код, несоответствующий дизайн-системе. Одноразовая генерация правил создаёт единый источник правды между Figma и кодом, что особенно важно при масштабировании (много экранов, несколько дизайнеров).

**Источник:** [Claude Code + Figma MCP: The Complete Designer Workflow](https://olyacooper.medium.com/claude-code-figma-mcp-the-complete-designer-workflow-56f3d7f22a6f) — Olya Cooper, Medium

**Дата:** 2026-10-14

## AI Design Tool от Anthropic: Трекинг

### Статус: Research Preview (запущен 17 апреля 2026)

**Дата релиза:** 17 апреля 2026 — research preview.

**Доступность:** Claude Pro ($20/мес), Max ($100/$200/мес), Team ($30/чел/мес), Enterprise (кастом). НЕ доступен на бесплатном плане. GA-дата не объявлена.

**Функциональность:**
- Генерация дизайн-систем, прототипов, сайтов, слайд-деков, one-pagers
- Inline-комменты, прямые правки, кастомные слайдеры для лейаута/цвета/спейсинга
- Web capture tool — захват элементов с живого сайта
- Импорт: текст, изображения, DOCX, PPTX, XLSX, кодовая база
- Экспорт: PDF, PPTX, Canva, standalone HTML, внутренний URL для шеринга
- Handoff в Claude Code одной командой
- Работает на Claude Opus 4.7

**Интеграции:**
- **Figma**: Code to Canvas (февраль 2026) — конвертация AI-кода в редактируемые Figma-файлы
- **Canva**: прямой экспорт
- **Май 2026 (новое):** Anthropic добавил Claude-коннекторы для **Adobe, Blender, Ableton, Affinity, Autodesk Fusion** — расширение в креативные инструменты

**Ограничения:**
- Критическая проблема с токенами: Pro-пользователи исчерпывают лимит за ~30 минут
- Нет возврата из Claude Code обратно в Claude Design
- Редактирование дизайн-системы только через промпты
- Нет UX-research фич: predictive heatmaps, accessibility audits, usability scores

**Ценообразование:** Включено в существующие тарифы без доплаты. Основной pain point — токенные лимиты на Pro-плане.

**Сравнения с конкурентами:**
- **vs Figma Make:** Claude Design выигрывает на ideation, Figma — на collaboration и handoff. Лучший результат — гибридный подход
- **vs v0 (Vercel):** Claude Design более визуальный и ориентирован на прототипирование, v0 — на production-код
- **vs Canva/Adobe:** Claude Design не пытается быть редактором, а мостом между идеей и реализацией

**Реакция сообщества:**
- Акции Adobe и Figma упали после запуска, но Figma подняла прогноз выручки на год в мае 2026
- Reddit: поляризация — от "magic" до "не заменит Figma". Консенсус: дополняет, не заменяет
- Главный фрикшн: token limits, а не качество генерации
- CPO Anthropic покинул борд Figma — сигнал о конкурентном позиционировании

**Обновления за май 2026:**

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Structured onboarding дизайн-системы для Claude** — перед работой с Claude Code загрузите токены (цвета, типографика, спейсинг) через `get_variable_defs` в Figma MCP. Без этого Claude генерирует «похожий, но не точный» код. Одна статья показала zero translation loss при правильной настройке.

2. **Brand Kit Skill** — создайте Claude Skill, который автоматически извлекает визуальный стиль из продакшен-сайта и применяет ко всем будущим генерациям. Один раз настроил — забыл.

3. **Claude Design для Product Discovery** — используйте Claude Design на этапе discovery для быстрой генерации интерактивных прототипов (4x ускорение). PM описывает гипотезу текстом → получает кликабельный прототип → тестирует на стейкхолдерах.

4. ⭐ **ЗАПОМНИТЬ — Гибридный воркфлоу Claude Design + Figma:** Консенсус из нескольких статей: Claude Design upstream (ideation, first draft), Figma downstream (collaboration, polish, handoff). Не «или-или», а последовательная связка. Это позволяет получить скорость AI без потери контроля профессионального инструмента.

5. ⭐ **ЗАПОМНИТЬ — Роль дизайнера меняется, но не исчезает:** Статьи за неделю единогласны: дизайнеры, которые адаптируются и берут роль «AI design director» (формулирует intention, курирует результат), выигрывают. Те, кто делает commoditized pixel-pushing — в зоне риска. Ключевой навык: умение направлять AI, а не заменяться им.

6. **Креативные коннекторы** — в мае Anthropic добавил интеграции с Adobe, Blender, Autodesk Fusion, Affinity, Ableton. Если вы работаете в этих инструментах — стоит попробовать подключение к Claude.

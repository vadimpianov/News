## AI Design Tool от Anthropic — трекинг

### Статус на 15 октября 2026

**Название:** Claude Design (ранее анонсирован как «AI Design Tool»)

**Хронология:**
- **Февраль 2026:** Figma и Anthropic заключили партнёрство — Code to Canvas: интерфейсы, созданные в Claude Code, конвертируются в редактируемые Figma-дизайны ([CNBC](https://www.cnbc.com/2026/02/17/figma-anthropic-ai-code-designs.html))
- **Апрель 17, 2026:** Запуск Claude Design в рамках Anthropic Labs. Работает на Claude Opus 4.7. Генерирует прототипы, слайды, макеты по текстовому описанию ([Habr](https://habr.com/ru/news/1024800/), [WinBuzzer](https://winbuzzer.com/2026/04/18/anthropic-launches-claude-design-figma-canva-xcxwbn/))
- **Май 2026:** Figma объявила о собственном AI-агенте с интеграциями Anthropic и OpenAI ([Dataconomy](https://dataconomy.com/2026/05/21/figma-ai-design-agent-openai-anthropic-integrations/))
- **Июнь 17, 2026:** Крупное обновление «Stays on brand» — импорт дизайн-систем, синхронизация с Claude Code через /design, canvas-редактор, коннекторы (Adobe, Canva, Gamma, Miro, Replit, Vercel, Wix). 1 млн пользователей за первую неделю ([Anthropic Blog](https://claude.com/blog/claude-design-stays-on-brand-for-daily-work))
- **Сентябрь 2026:** Claude Design интегрирован в каждый диалог Claude (чат, Claude Code, Artifacts). Standalone-версия на claude.ai/design будет закрыта (дата уточняется)
- **Октябрь 8, 2026:** По неподтверждённым данным, стал доступен на бесплатном тарифе ([omidsaffari.com](https://omidsaffari.com/blog/claude-design-free))
- **Октябрь 15, 2026 (сегодня):** Claude Design, Slides и Docs включаются по умолчанию для Enterprise ([support.claude.com](https://support.claude.com/en/articles/14604406-claude-design-admin-guide-for-team-and-enterprise-plans))

**Функциональность:**
- Конверсационная генерация: чат слева, live canvas справа
- Прототипы, слайды, лендинги, one-pagers
- Импорт дизайн-систем из GitHub, файлов или загрузки
- Экспорт: PDF, PPTX, HTML, Canva, Claude Code (handoff bundle)
- /design-sync для синхронизации дизайн-системы из терминала
- Canvas-редактирование: drag, resize, align

**Интеграции:** Figma (через Claude Code → Figma), Adobe, Canva, Gamma, Miro, Replit, Vercel, Wix

**Ценообразование:** Бета на Pro ($20), Max ($100/$200), Team ($30/user), Enterprise. Design использует общий лимит Claude. Бесплатный доступ — неподтверждён.

**Сравнение с конкурентами:**
- **vs Figma Make:** Figma Make лучше для команд с дизайн-системой в Figma, Claude Design — для быстрого exploration
- **vs Figma (полный):** Figma лидирует в компонентных библиотеках, масштабных дизайн-системах, командной работе, dev handoff, векторном редактировании
- **vs v0 (Vercel):** Claude Design предлагает более широкий спектр (слайды, документы), v0 более узко фокусирован на web-компонентах

**Реакция сообщества:** Акции Figma упали ~5–7% после запуска. Дизайнеры видят инструмент как дополнение, не замену Figma. Основная критика: нет нативного Figma-экспорта, базовая коллаборация, нет истории версий.

## Выводы

### Что применить прямо сейчас

1. **Claude Design → Enterprise доступен с сегодняшнего дня.** Если ваша команда на Enterprise-плане — Claude Design, Slides и Docs теперь включены. Попросите администратора проверить Organization settings > Artifacts.

2. **Prototype Playground по модели Notion** — ⭐ **ЗАПОМНИТЬ**. Идея Brian Lovin: общий Next.js-репозиторий, где каждый дизайнер создаёт прототипы в отдельной папке. Прототип в браузере обнажает edge cases, которые макет в Figma прячет. Особенно ценно для AI-фич, где нужна реальная модель.

3. **Handoff bundle из Claude Design** — самый полезный экспорт. Пакет с дизайн-токенами, компонентами и ассетами передаётся в Claude Code для генерации production-кода. Figma остаётся для финальной полировки.

4. **Custom SKILL.md для дизайн-роли** — превращает Claude в «старшего дизайн-партнёра» с пониманием accessibility, паттернов взаимодействия и frontend-ограничений. Один раз написал — работает во всех проектах.

5. **Goodpatch: Figma для нового, Storybook + Claude Code для существующего** — ⭐ **ЗАПОМНИТЬ**. Чёткое разделение: новый дизайн в Figma, итерации на существующем UI через Storybook + Claude Code. Эффективно при работе с живым продуктом.

6. **Всегда начинай с search_design_system** — правило из Figma Skills. Прежде чем генерировать компоненты — проверь, есть ли они в дизайн-системе. Избегай дублирования.

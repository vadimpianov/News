## 3. AI Design Tool от Anthropic — трекинг

### Статус: Claude Design (бывш. AI Design Tool)

| Параметр | Данные |
|---|---|
| **Дата запуска** | 17 апреля 2026, research preview |
| **Текущий статус** | Beta (с июня 2026). Standalone-сайт claude.ai/design **закрывается 14 декабря 2026** |
| **Модель** | Claude Opus 4.7 (vision) |
| **Доступность** | Pro ($20/мес), Max, Team, Enterprise |
| **Ценообразование** | Включён в подписку, расходует общие лимиты с чатом и Claude Code |

### Функциональность
- Генерация прототипов, слайдов, лендингов, wireframes, маркетинговых материалов из текстового описания
- Импорт из текста, изображений, DOCX/PPTX/XLSX, кодовой базы, захват элементов с живых сайтов
- Интерактивные «frontier»-прототипы: голос, видео, шейдеры, 3D, встроенный AI
- Прямое редактирование текста на канвасе, комментарии, ползунки для spacing/color/layout
- Handoff в Claude Code одной командой

### Дизайн-система
- При онбординге Claude строит дизайн-систему из кодовой базы и дизайн-файлов
- Импорт через GitHub-репозиторий, дизайн-файлы или raw-данные
- Автоматическая сверка вывода с дизайн-системой перед показом (с июня 2026)
- Команды: `/design-sync` для двусторонней связки с Claude Code

### Экспорт
- URL (внутри организации), PDF, PPTX, Canva, standalone HTML
- **Нативного экспорта в Figma НЕТ** (по состоянию на ноябрь 2026)

### Интеграции
- Claude Code: двусторонняя связка через /design и /design-sync
- Canva: партнёрство (Anthropic позиционирует как дополнение, не замену)
- Figma: через MCP и community skills (/prototype-to-figma), но не нативная интеграция Claude Design

### Сравнение с конкурентами

| Инструмент | Подход | Сильные стороны | Слабые стороны |
|---|---|---|---|
| **Claude Design** | Промпт → интерактивный прототип (HTML/React) | Импорт дизайн-системы из кода, handoff в Claude Code | Нет Figma-экспорта, нет version history, дорогой по токенам |
| **Figma Make** | Промпт → нативные Figma-компоненты | Живёт внутри Figma, нативные варианты и auto-layout | Beta, кредитная система, может «забывать» контекст |
| **Google Stitch** | Промпт → прототип | Интеграция с Google-экосистемой | Меньше контроля над дизайн-системой |

### Реакция сообщества
- Акции Figma упали ~5% в день запуска Claude Design
- Figma акции −41% с начала года (частично из-за конкуренции AI-инструментов)
- Дизайнеры: «полезен для exploration, но вкус не делегируешь» (Nervegna, Substack)
- Консенсус: Claude Design для ранней exploration → Figma для production и handoff

### Новое за этот период
- **Standalone закрывается 14 декабря 2026** — дизайн-системы нужно мигрировать
- Дизайн теперь живёт как артефакт внутри обычных Claude-чатов
- Figma отчиталась о сильном спросе на AI-кредиты (80%+ крупных клиентов используют еженедельно)

## 5. Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **⭐ ЗАПОМНИТЬ: Design.md как контракт для AI.** Опыт Zalando показывает: маленькие design.md-файлы рядом с компонентами — это «документация для AI». Они позволяют любому AI-инструменту (Claude Code, Figma MCP) генерировать on-brand результат без ручной настройки каждый раз. Это дешевле и надёжнее, чем полагаться на промпты.

2. **Сначала бренд-кит, потом генерация.** Forbes и несколько гайдов подтверждают: без загруженных brand rules AI выдаёт шаблонный Inter + фиолетовый градиент. Первый шаг в любом AI-воркфлоу — загрузить DESIGN.md или brand kit.

3. **Разделяй exploration и production.** Консенсус всех обзоров: Claude Design / AI-инструменты — для быстрой exploration (5 направлений за 15 минут вместо 2 дней). Figma — для production, компонентов и handoff. Смешивать этапы — терять время.

4. **Prompt ≠ brief.** Лучшие практики: не начинать генерацию сразу. Сначала описать контекст в чате, попросить Claude задать уточняющие вопросы, и только потом переходить к визуалу. «Version 1 will be messy» — это нормально.

5. **⭐ ЗАПОМНИТЬ: AI-ready дизайн-система.** Фундамент из кейса Zalando: агностичные дизайн-токены, Figma Code Connect, документация для людей И для AI (design.md), маленькие файлы. Это инвестиция, которая окупается при любом AI-инструменте.

6. **Миграция Claude Design → Claude до 30 ноября.** Практический совет: поставить внутренний дедлайн на 2 недели раньше закрытия (14 декабря), чтобы успеть исправить проблемы. Чаты и комментарии НЕ переносятся — сохранить вручную.

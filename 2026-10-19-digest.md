**3 Simple Tricks That Will Help You Iterate Your Design with Claude Design**

**Суть:** Три конкретных приёма работы с Claude Design. (1) **Итерация локально, затем глобально** — доведите до идеала один компонент (карточку, хедер), затем попросите Claude применить те же решения ко всему макету. ## AI Design Tool от Anthropic: трекинг

### Статус: Claude Design (Research Preview → GA)
- **Анонс:** 17 апреля 2026, одновременно с Claude Opus 4.7
- **Крупное обновление (Claude Design 2.0):** 17 июня 2026

### Функциональность
- Генерация прототипов, слайдов, лендингов и маркетинговых материалов через диалог с AI
- Работает на Claude Opus 4.7
- Импорт дизайн-систем из GitHub-репозиториев, дизайн-файлов или загрузок (с июня 2026)
- Canvas-редактирование: drag, resize, align элементов (с июня 2026)
- Панель Tweaks для правки типографики, цвета, отступов без расхода чат-токенов
- Команда `/design-sync` для синхронизации React дизайн-системы из Claude Code

### Интеграции
- **Figma:** Code to Canvas (февраль 2026) — конвертация кода Claude Code в редактируемые Figma-слои. Обратное: Figma → Claude Code через Figma MCP
- **Экспорт:** PDF, PPTX, HTML, Canva. Прямой экспорт в Figma-формат пока отсутствует
- **Claude Code:** двусторонний handoff через /design-sync

### Ценообразование
- Доступен на планах Pro, Max, Team, Enterprise
- Enterprise — usage-based биллинг по API-ставкам
- Отдельный usage-лимит был удалён в обновлении Claude Design 2.0 (июнь 2026)

### Конкуренты
- **Figma Make:** использует Claude Sonnet 4 под капотом, работает внутри Figma, подходит для тех, кто уже в экосистеме Figma
- **v0 (Vercel):** ближе к code-генерации, чем к дизайн-инструменту
- **Canva AI:** таргетирует не-дизайнеров, Claude Design позиционируется как «мост» между Canva и Figma
- Акции Figma упали ~5–7% после анонса Claude Design, но потом Figma подняла прогноз на год

### Реакция дизайн-сообщества
- Дизайнеры-практики оценивают инструмент как сильный для первых 70% черновика
- Финальная полировка (доступность, адаптивность, нюансы бренда) — по-прежнему вручную
- Критика: нет слоёв, нет компонентов, нет булевых операций, нет auto-layout — это не canvas-редактор
- Позитив: скорость исследования вариантов выросла на порядок (вместо 2–3 направлений — десятки)

### Новое за этот период
**AI Design Tool от Anthropic: новых данных за 16–18 октября нет.** Последнее значимое обновление — Figma Config India (15–16 октября), где Figma Specs и Code Layers усиливают экосистему Claude + Figma, но это инициатива Figma, не Anthropic.

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Фронтлоадинг контекста в промпт.** Перед генерацией в Claude Design или Claude Code описать аудиторию, тон, структуру макета и ограничения. Детальный промпт = детальный результат, абстрактный = посредственный.

2. **Дизайн-система как входные данные, а не результат.** Загрузить токены, шрифты, гайдлайны, логотипы и 1–2 готовых экрана до начала работы с Claude — это главный рычаг для on-brand генерации.

3. **Итерация: сначала локально, потом глобально.** Довести до идеала один компонент, затем попросить Claude применить решения ко всему макету. Это эффективнее, чем править весь макет целиком.

4. **Прототипировать состояния, не экраны.** Claude Design легко генерирует happy path, но пустые состояния, ошибки, загрузка и edge cases нужно запрашивать явно.

5. ⭐ **ЗАПОМНИТЬ: Figma Specs как источник истины для AI-агентов.** Новый Figma Specs Editor позволяет записать дизайн-язык команды в Markdown, и AI-агенты (включая Claude через MCP) будут читать эти спецификации перед генерацией. Это решает ключевую проблему off-brand результатов AI. Рекомендация: начать описывать дизайн-систему в Figma Specs уже сейчас, чтобы подготовить базу для AI-воркфлоу.

6. ⭐ **ЗАПОМНИТЬ: Запрос допущений после генерации.** Попросить Claude перечислить допущения о пользователях и иерархии после генерации макета — это UX-ревью «бесплатно». Вскрывает пробелы, которые дизайнер мог не заметить.

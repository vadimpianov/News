## AI Design Tool от Anthropic — Трекинг

### Статус: Research Preview (с 17 апреля 2026)

**Дата релиза:** 17 апреля 2026 (research preview)  
**Доступность:** Claude Pro ($20/мес), Max ($100/$200/мес), Team, Enterprise  

**Функциональность:**
- Генерация дизайнов, прототипов, слайдов, one-pagers из текстового описания
- Загрузка изображений, документов (DOCX, PPTX, XLSX), чтение кодовой базы
- Web Capture — захват элементов с сайта для точного прототипирования
- Автоматическое построение дизайн-системы при онбординге (читает код + Figma-файлы)
- Итерация: чат, инлайн-комментарии, прямое редактирование, кастомные слайдеры
- Powered by Claude Opus 4.7

**Интеграции:**
- Экспорт: PDF, PPTX, URL, Canva (полностью редактируемый)
- Хендофф в Claude Code (single instruction)
- Figma: через Figma MCP + Code to Canvas (февраль 2026)
- Новые коннекторы (май 2026): Adobe, Blender, Autodesk Fusion, Ableton, Splice, Affinity

**Ценообразование:**
- Включено в подписку Pro/Max/Team/Enterprise
- Критичная проблема: очень высокий расход токенов (Opus 4.7 vision ≈ 3x стоимость текста)
- Пользователи Pro жалуются на исчерпание лимита за 30 минут (2 промпта = 95% лимита)

**Сравнение с конкурентами:**
| | Claude Design | v0 (Vercel) | Figma AI |
|---|---|---|---|
| Подход | Диалоговый, генерация live-кода | Full-stack React + deploy | Canvas + auto-layout |
| Сильная сторона | Чтение кодбейза/дизайн-системы | One-click deployment | Collaboration + governance |
| Слабость | Расход токенов, нет нативной Figma | Нет system extraction | Ограничена design-only |
| Цена | от $20/мес | от $20/мес | от $15/мес |

**Реакция сообщества:**
- Figma: акции упали на 5-7% после запуска
- Mike Krieger (CPO Anthropic) покинул совет директоров Figma 14 апреля, за 3 дня до запуска
- Reddit r/ClaudeAI: жалобы на расход токенов, но признание качества output
- Консенсус: Claude Design не заменяет Figma для production, но убивает этап первого черновика
- Лучший воркфлоу: Claude Design upstream (идеация) → Figma downstream (production)

**Обновление мая 2026:**

## Выводы: что применить в работе дизайнера

1. **Структурирование дизайн-системы = качество AI-output.** Чем лучше описаны компоненты в Figma (descriptions, naming conventions, annotations), тем качественнее Claude генерирует UI через MCP. Это инвестиция не только для людей, но и для AI-агентов.

2. **Claude Design → первый черновик, Figma → production.** Гибридный воркфлоу: используй Claude Design для быстрой генерации 5-10 вариантов лендингов/экранов за минуты, затем бери лучший в Figma для доработки. Экономия — пропуск 2-недельных дизайн-спринтов для exploration-фазы.

3. **Claude Skills как «уравнитель» команды.** Настроенные Skills с привязкой к дизайн-токенам позволяют джуниорам выпускать UI того же качества, что и сеньоры. Это меняет подход к онбордингу и распределению задач.

4. **⭐ ЗАПОМНИТЬ: Описания компонентов в Figma как контекст для AI.** Figma MCP передаёт descriptions компонентов как контекст агенту. Это значит: каждый компонент в дизайн-системе должен иметь чёткое описание (когда использовать, ограничения, варианты) — это делает AI-workflow кратно эффективнее. Инвестиция в документацию компонентов окупается не только для людей, но и для AI.

5. **Бороться с «AI-шным» видом через Skills.** Без кастомных Skills Claude генерирует generic UI. С правильно настроенными Skills (типографика, spacing, палитра из реальной системы) — output неотличим от ручной работы.

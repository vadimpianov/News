## AI Design Tool от Anthropic: трекинг

### Статус: Research Preview (запущен 17 апреля 2026)

**Дата релиза**: 17 апреля 2026 — research preview
**Доступность**: Claude Pro, Max, Team, Enterprise. Free план — НЕ поддерживается. URL: claude.ai/design

**Функциональность**:
- Генерация дизайнов, прототипов, слайдов, one-pagers через диалог
- Inline-комментарии, прямое редактирование текста, слайдеры для тонкой настройки (spacing, color, layout)
- Автоматическое создание дизайн-системы при онбординге (читает кодовую базу и дизайн-файлы)
- Handoff bundle — передача в Claude Code одной командой
- Шаринг внутри организации с контролем доступа (view/edit)

**Экспорт**: Canva, PDF, PPTX, HTML, Claude Code

**Интеграции (обновлено 1 мая 2026)**:
- Figma: через Code to Canvas (февраль 2026) — двусторонняя связь
- Adobe Creative Cloud: коннектор к 50+ инструментам (28 апреля 2026)
- Blender, Autodesk Fusion, SketchUp: 3D-коннекторы (28 апреля 2026)
- Ableton, Splice, Resolume: аудио/видео (28 апреля 2026)

**Ценообразование**: Входит в существующие подписки. Потребляет значительно больше токенов — Pro-план может быть исчерпан за ~30 минут активной работы.

**Сравнение с конкурентами**:
- vs Figma: не замена, а параллельный инструмент. Claude Design генерирует живой HTML/React, Figma — векторный редактор. Акции Figma упали при анонсе.
- vs v0/Vercel: Claude Design ближе к full-stack дизайну (слайды, one-pagers, не только веб)
- vs Canva: Claude Design конкурирует напрямую, экспорт в Canva — мостик
- vs Adobe Firefly: Adobe стала партнёром (коннектор), а не конкурентом

**Реакция дизайн-сообщества**:
- Профессиональные дизайнеры скептичны: «не заменит Figma для серьёзной работы»
- Разработчики и PM-ы в восторге: ускоряет прототипирование в разы
- Консенсус: «80% пути», но последние 20% требуют профессиональных навыков
- Главная боль: лимиты токенов на Pro-плане

**Ключевые ограничения**:
- Точность воспроизведения: 50-75%
- Сложные интерактивные состояния, кастомные анимации, edge-case breakpoints требуют доработки
- Проблемы с консистентностью spacing и типографики без явной дизайн-системы
- Быстрое исчерпание лимитов

## Выводы: приёмы для работы дизайнера

### 1. ⭐ ЗАПОМНИТЬ: Design System First — не пропускать этап настройки дизайн-системы
Claude Design работает значительно лучше, когда вы начинаете с полноценной дизайн-системы: токены, шрифты, цвета, сетка, компоненты. Без этого Claude подставляет свои дефолты (тени, скругления, spacing), и результат выглядит «как AI». Принцип: «тишина = дефолты» — если что-то не задано явно, Claude примет решение за вас.
**Почему важно**: Это меняет подход к промптингу — нужно думать о системе, а не об отдельных экранах.

### 2. ⭐ ЗАПОМНИТЬ: 8px Grid System от Claude Design
Claude Design использует базовый юнит 8px с множителями (4, 8, 16, 24, 32, 48, 64, 96). Это можно перенести в свою дизайн-систему как валидированную AI-сетку. Всё, что «ложится на сетку» — выглядит консистентно.

### 3. Handoff Bundle как новый стандарт передачи
Вместо Zeplin/Inspect — handoff bundle из Claude Design в Claude Code одной командой. Это сокращает цикл «дизайн → код» до минут. Стоит следить за развитием этого формата.

### 4. Лучший результат — при переработке существующего
Reddit и тестеры подтверждают: лучший аутпут получается, когда загружаешь существующую презентацию/дизайн и просишь Claude переработать, а не генерировать с нуля.

### 5. Claude Design ≠ финальный дизайн
Инструмент — для экстернализации идей и быстрого прототипирования. Последние 20% (детали, edge cases, микро-взаимодействия) — это работа дизайнера с вкусом и опытом.

## AI Design Tool от Anthropic: трекинг

### Статус: Claude Design вышел из беты, доступен всем

**Хронология:**
- **17 апреля 2026** — запуск Claude Design как research preview для Pro, Max, Team, Enterprise
- **17 июня 2026** — крупное обновление: импорт дизайн-систем, канвас-редактор, синхронизация с Claude Code, коннекторы (Adobe, Canva, Miro, Vercel, Wix)
- **Июль 2026** — переработка handoff-процесса между Claude Design и Claude Code (The New Stack, Fast Company)
- **8 октября 2026** — **выход из беты, доступен на всех планах включая Free**
- **15 октября 2026** — автовключение для Enterprise
- **14 декабря 2026** — закрытие standalone-сайта claude.ai/design

**Функциональность:**
- Создание прототипов, слайд-деков, one-pagers, маркетинговых материалов через разговор
- Импорт дизайн-системы из GitHub-репо, дизайн-файлов или загруженных ассетов
- Канвас с drag/resize/align, инлайн-комментарии, слайдеры для spacing/color/layout
- Экспорт в PDF, PowerPoint, HTML
- Коннекторы: Adobe, Canva, Gamma, Miro, Replit, Vercel, Wix
- Синхронизация с Claude Code через `/design-sync` и `/design`
- Работает на Claude Opus 4.7

**Интеграции с Figma:**
- Нативного экспорта в Figma нет
- Workaround: html.to.design (Chrome-расширение) и MCP-based workflow (third-party)
- Figma Make использует Claude Sonnet 4 под капотом

**Ценообразование:**
- Включён в стоимость всех планов (Free, Pro, Max, Team, Enterprise)
- Использует общий лимит с чатом и Claude Code
- Квота расходуется быстро при интенсивной работе

**Сравнения с конкурентами:**
- vs Figma Make: Claude Design лучше для быстрых концептов, Figma — для production (компоненты, коллаборация, dev handoff, версионирование)
- vs Figma: не замена, а дополнение; Claude Design — для ideation, Figma — для точной работы
- vs Canva: позиционируется как конкурент для маркетинговых материалов

**Реакция дизайн-сообщества:**
- В день запуска (апрель): акции Figma -6%, Wix -5%
- Дизайнеры на HN выражали опасения по поводу лимитов и однородности стиля
- Ben Blumenrose (основатель Designer Fund): предположил, что это «ещё один вход в дизайн для сотен миллионов людей», как Canva
- Консенсус: полезен для первых 70% черновика, но не заменяет дизайн-мышление и точную работу

**Новые продукты (октябрь 2026):**
- **Claude Dashboards** (бета, платные планы) — живые дашборды с подключением к Snowflake, BigQuery, Databricks, Salesforce
- **Claude Motion** (бета, Team/Enterprise) — анимированные объяснения, генерирует редактируемый код, не видео

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Claude Design теперь бесплатен** — можно начать использовать для быстрого прототипирования лендингов и презентаций без подписки. Порог входа снят.

2. **Принцип «10 вариантов → ремикс лучших»** от Нейта Парротта — генерировать ~10 направлений, выбирать 2-3 сильнейших и просить Claude комбинировать их. Это меняет динамику дизайн-ревью: вместо обсуждения одного варианта — выбор из множества.

3. ⭐ **ЗАПОМНИТЬ — Роль дизайнера смещается к оценке:** Goodpatch и несколько авторов подчёркивают: с AI рутинная генерация ускоряется, и ценность дизайнера — в способности оценивать, критиковать и направлять. Навык «дизайн-критика» становится важнее навыка «рисования».

4. **GitLab-подход: Claude Project с загруженной дизайн-системой** — вместо того чтобы Claude угадывал компоненты, загрузить библиотеку как контекст. Решает проблему «дженерик-стиля» в генерации.

5. ⭐ **ЗАПОМНИТЬ — «50+ часов на рефайнмент»:** UX Tools честно описывает, что AI ускоряет старт, но основное время уходит на доводку. Планировать бюджет времени соответственно: ~20% генерация, ~80% уточнение.

6. **Задавать эстетическое направление в промпте** — без указания шрифтов, цветов, мудбордов Claude выдаёт дженерик. Импортировать дизайн-систему или хотя бы указать конкретные шрифты и палитру.

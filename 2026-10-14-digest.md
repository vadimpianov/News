**Суть:** 8 октября Anthropic выпустил два новых продукта (Claude Dashboards и Claude Motion) и перевёл Claude Design, Docs и Slides из беты в GA (General Availability). Ключевые изменения для дизайнеров:

- **Claude Design теперь на всех планах**, включая бесплатный. Ранее был доступен только платным подписчикам.

- **Standalone Claude Design (claude.ai/design) закрывается 14 декабря 2026**. Дизайн-системы можно мигрировать, но чаты и комментарии не переносятся.

По данным Anthropic, за период беты было создано более **45 миллионов** документов, слайдов и дизайнов.

## AI Design Tool от Anthropic: трекинг

### Статус: вышел из беты, интегрирован в основной Claude

**Текущее состояние (октябрь 2026):**
- **Доступность:** GA (General Availability) с 8 октября 2026. Доступен на всех планах, включая Free.
- **Standalone-версия (claude.ai/design):** закрывается **14 декабря 2026**. Миграция дизайн-систем возможна, чаты и комментарии не переносятся.
- **Включение по умолчанию для Enterprise:** с 15 октября 2026 (кроме HIPAA-организаций).

**Функциональность:**
- Генерация UI/прототипов/слайдов/лендингов из промпта через визуальный канвас
- Работает на Claude Opus 4.7
- Экспорт: HTML, PDF, PPTX, Canva. Нативного Figma-экспорта нет
- Handoff-бандл для Claude Code для дальнейшей реализации
- Проверка соответствия дизайн-системе перед показом результата
- `/design-sync` — двунаправленная синхронизация с Claude Code

**Интеграции:**
- **Figma:** через Code to Canvas (фича Figma, февраль 2026) — код из Claude конвертируется в редактируемые Figma-слои. Figma Make использует Claude Sonnet 4 под капотом.
- **Canva:** партнёрство подтверждено
- **Microsoft:** Word/PowerPoint интеграция анонсирована, но детали не раскрыты

**Ценообразование:**
- Включён в подписку Claude (все планы). Использует общий пул токенов с чатом и Claude Code.

**Сравнение с конкурентами:**
| | Claude Design | Figma Make | v0 (Vercel) |
|---|---|---|---|
| Модель | Claude Opus 4.7 | Claude Sonnet 4 | Собственная |
| Экспорт в Figma | Через Code to Canvas | Нативно | Нет |
| Фокус | Прототипы + слайды + лендинги | Figma-нативные дизайны | React-компоненты |
| Цена | Входит в Claude | Входит в Figma | Отдельная подписка |

**Реакция дизайн-сообщества:**
- Акции Figma падали на ~5% при запуске Claude Design в апреле
- Консенсус: инструменты скорее дополняют друг друга, чем конкурируют
- Более 45 млн артефактов создано за период беты
- Критика: нет нативного экспорта в Figma, базовое командное редактирование, нет истории версий

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Итерация по слоям, а не одним промптом.** Проверенный подход: информационная архитектура → типографика/spacing → цвет → микроинтеракции. Один промпт, даже детальный, не даёт финальный результат.

2. **Дизайн-система как «скилл» для Claude.** Можно один раз сгенерировать файл правил дизайн-системы (через Claude Code + Figma MCP), и все дальнейшие сессии будут соблюдать токены, компоненты и гайдлайны.

3. **Claude Design → Claude Code пайплайн.** Claude Design для быстрых визуальных исследований, Claude Code для реализации. Figma остаётся каноническим хранилищем дизайн-системы.

4. ⭐ **ЗАПОМНИТЬ: «Убрать AI-look» через skill.md.** Японская методика Hexabase: определить tone & manner, правила компонентов и a11y в файле skill.md, чтобы Claude генерировал UI, неотличимый от ручной работы. Это решает главную проблему AI-генерации — все результаты выглядят одинаково.

5. ⭐ **ЗАПОМНИТЬ: один дизайнер на 7 продуктов.** Кейс Ryan Mather из Anthropic показывает, что с Claude Design + Claude Code один дизайнер может поддерживать 7 продуктов. Стратегия: сначала дизайн-система и ключевые страницы, потом масштабирование.

6. **Дизайнер может открывать PR.** Кейс из Substack-рассылки: дизайнер через Claude Code доводит прототип до рабочего кода и открывает PR, минуя передачу разработчику. Это меняет роль дизайнера в команде.

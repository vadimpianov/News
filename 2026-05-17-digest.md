## AI Design Tool от Anthropic — трекинг

### Статус: Research Preview (запуск 17 апреля 2026)

**Дата релиза:** 17 апреля 2026, Research Preview
**Доступность:** Claude Pro, Max, Team, Enterprise. Бесплатный план НЕ поддерживается.
**URL:** claude.ai/design

**Функциональность:**
- Генерация прототипов, слайдов, лендингов, one-pagers, инфографики через диалог
- Итерация: чат, инлайн-комменты, прямые правки текста, кастомные слайдеры (Tweaks)
- Авто-генерация дизайн-системы из кодовой базы/дизайн-файлов (цвета, типографика, компоненты)
- Handoff Bundle → Claude Code для перехода к production-коду
- Работает на Claude Opus 4.7

**Экспорт:** PDF, PPTX, standalone HTML, Canva (полностью редактируемые файлы)

**Интеграции:**
- **Figma:** Code to Canvas (февраль 2026) — конвертация кода в редактируемые Figma-фреймы. MCP-коннектор для двусторонней связи.
- **Canva:** экспорт в Canva с полной редактируемостью
- **PPTX:** экспорт в PowerPoint-формат
- Word: подтверждения интеграции пока нет

**Ценообразование:** входит в подписку Pro ($20/мес), Max ($100–200/мес), Team, Enterprise. Отдельной цены нет. Ограничение: высокое потребление токенов, лимиты Max плана быстро расходуются.

**Конкуренция:**
- vs Figma: Claude Design не заменяет Figma, но подтачивает позиции — убирает необходимость ждать дизайнера (Harry Stebbings). Figma лучше для collaboration и handoff; Claude лучше для быстрой идеации.
- vs v0 / Lovable: Claude Design генерирует HTML/CSS/React, как и конкуренты, но интегрирован в экосистему Claude (Code, Routines, Skills)
- vs Adobe: Adobe добавил коннектор к Claude — скорее партнёрство, чем конкуренция
- vs Canva: Anthropic заявляет, что Claude Design дополняет Canva, а не конкурирует

**Реакция дизайн-сообщества:**
- Figma акции упали на 7% после запуска; затем Figma повысила годовой прогноз
- Reddit разделился: серьёзные дизайнеры не бросят Figma, но 72% из 1200 дизайнеров (Dribbble/State of AI Design 2026) теперь используют Claude для генерации кода
- 25-летний ветеран дизайна на Reddit: «Большая часть UX и визуального дизайна — это поддержка дизайн-систем с минимальными вариациями. Это и создано для автоматизации.»
- Главная жалоба: потребление токенов. Дизайн-система при onboarding сжирает почти весь недельный лимит.

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Tweaks-панель вместо чата для визуальных правок** — слайдеры типографики, цвета, spacing density и порядка секций НЕ расходуют токены. Правило: если можно починить слайдером — не печатай. Это экономит 30–50% бюджета токенов.

2. **`create_design_system_rules` через Figma MCP** — генерирует файл правил, который обучает Claude конвенциям команды (именование токенов, структура папок, паттерны компонентов). Настраивается один раз, работает постоянно.

3. **Claude Design для ideation, Figma для collaboration** — ⭐ **ЗАПОМНИТЬ**: умный воркфлоу использует Claude Design И Figma, а не вместо. Claude побеждает на фазе идеации и первого драфта (5 концептов за 10 минут), Figma — на коллаборации, хендоффе и глубине экосистемы. Не нужно выбирать один инструмент.

4. **Дизайн целой фичи за одну встречу с инженером** — суперсила Claude Design: мгновенная генерация мокапов удерживает обсуждение на уровне концепций и user flows вместо пиксельных деталей.

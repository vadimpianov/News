## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Design System as Code → Claude.** Импортируйте свою дизайн-систему в Claude через `/design-sync` — Claude будет проверять свои результаты на соответствие вашим компонентам ДО показа. Это убирает «AI-generic» вид макетов.

2. **Figma MCP как мост.** Подключив Figma MCP Server к Claude Code, вы получаете двусторонний поток: Claude читает токены и компоненты из Figma, а Code to Canvas возвращает код обратно в редактируемые фреймы. Это ближайший путь к бесшовному хэндоффу.

3. **Claude Design → быстрые варианты, Figma → продакшн.** Консенсус из обзоров: используйте Claude Design upstream для быстрой генерации 3-5 вариантов, затем лучший вариант доводите в Figma. Не пытайтесь делать финальный дизайн в Claude Design.

4. ⭐ **ЗАПОМНИТЬ: Миграция до 14 декабря.** Если используете standalone Claude Design — перенесите дизайн-системы СЕЙЧАС. Чаты и комментарии будут потеряны безвозвратно. Публичные ссылки перестанут работать.

5. **Claude как UX-ассистент, не UX-замена.** Все авторы сходятся: Claude — «быстрый джуниор для работы вокруг канваса». Генерация вариантов, аудит accessibility (WCAG 2.2), синтез исследований, UX-копирайтинг — да. Принятие дизайн-решений — нет.

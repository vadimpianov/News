## AI Design Tool от Anthropic: Трекинг

### Статус: Research Preview (с 17 апреля 2026)

**Название:** Claude Design (продукт Anthropic Labs)

**Дата релиза:** 17 апреля 2026 — research preview

**Доступность:** Claude Pro ($20/мес), Max, Team, Enterprise. Включён в подписку без дополнительной стоимости. Только PC-браузер, мобильного приложения пока нет.

**Функциональность:**
- Генерация: прототипы, слайд-деки, лендинги, one-pagers, интерактивные веб-страницы
- Движок: Claude Opus 4.7 (vision model)
- Дизайн-система: автоматическое чтение кодовой базы и дизайн-файлов, построение UI-кита
- Tweaks: слайдеры для типографики, цвета, spacing, border-radius — правки без промптов
- Inline-комментарии: точечная обратная связь на конкретных элементах
- Handoff: передача в Claude Code как структурированный implementation bundle

**Экспорт:** PPTX, PDF, HTML, Canva. Нет нативного экспорта в Figma.

**Интеграции:**
- Claude Code — прямой handoff для реализации
- Canva — экспорт дизайнов
- Нет прямой Figma-интеграции (хотя Figma MCP работает отдельно через Claude Code)
- Анонсированы коннекторы для Adobe, Blender, Ableton, Affinity, Autodesk Fusion (май 2026)

**Ценообразование:** Включён в Pro ($20/мес). Но token consumption критически высокий — Pro-лимит исчерпывается за ~30 минут. Max 20x — минимум для регулярной работы.

**Ограничения:**
- Односторонний handoff: после передачи в Claude Code нельзя вернуться в Claude Design
- Высокое потребление токенов
- Медленная генерация на сложных проектах
- Не подходит для масштабных дизайн-проектов
- Нет командной коллаборации уровня Figma

**Сравнение с конкурентами:**
| Инструмент | Сильная сторона | Слабость vs Claude Design |
|---|---|---|
| Figma | Production design, командная работа, dev handoff | Слабая идеация и генерация |
| v0 (Vercel) | Dev-ориентирован, React/Tailwind код | Нет PPTX/Canva экспорта |
| Figma Make | Генерация внутри Figma | Менее мощная модель |
| Galileo AI | UI-генерация | Уже экосистема |
| Adobe Firefly | Графика и изображения | Другой фокус (не UI) |

**Реакция рынка:**
- Акции Figma -7% в день запуска
- Майк Кригер (CPO Anthropic) покинул борд Figma
- 72% дизайнеров (опрос Dribbble, 1200 респондентов) используют Claude для code gen — рост с 18% за год
- Команда Datadog: цикл «бриф → мокап → ревью» сжался с недели до одного разговора

**Обновления за 17–19 мая 2026:**
- Anthropic приобрела Stainless ($300M+) — усиление SDK-инфраструктуры и MCP-коннекторов
- Добавлены коннекторы для Adobe, Blender, Ableton, Affinity, Autodesk Fusion

## Выводы

### Что применить прямо сейчас

1. **Дизайн-система — рычаг качества Claude Design.** Загрузите свою кодовую базу и Figma-файлы при первом запуске — Claude построит UI-кит и будет применять его ко всем проектам. Без этого результаты generic.

2. **Конкретные значения вместо описаний.** При работе с Claude Design используйте `border-radius: 0`, `font-family: 'Syne'`, `spacing: 8px grid` — не «сделай minimalist». Инструкция «This should not look AI-generated» тоже помогает.

3. **Tweaks для визуала, чат для структуры.** Если проблему можно починить слайдером — не пишите промпт. Чат — для концептуальных изменений. Это экономит токены.

4. **Claude Code Skills для Figma.** Создайте 3-4 скилла: аудит компонентов, генерация вариантов, проверка spacing-токенов, чтение дизайн-системы. Claude Code становится не просто кодером, а дизайн-партнёром.

5. ⭐ **ЗАПОМНИТЬ — «80/20 mental model».** 10 минут на 80% в Claude Design, остаток времени — на 20% экспертных решений (brand tone, edge cases, accessibility). Этот подход подтверждён несколькими независимыми источниками и выступлением дизайн-директора Claude.

6. ⭐ **ЗАПОМНИТЬ — Чистота Figma-файлов = качество Claude.** Если файлы неряшливые (неконсистентные имена, broken components, разбросанные стили) — Claude Code будет ошибаться. Ваша дисциплина в Figma напрямую определяет качество AI-результата.

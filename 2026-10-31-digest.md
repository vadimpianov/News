## AI Design Tool от Anthropic: трекинг

### Статус: Claude Design — полноценный продукт, standalone закрывается

**Хронология:**
- **Апрель 17, 2026** — запуск Claude Design (Anthropic Labs, research preview, на базе Claude Opus 4.7)
- **Февраль 2026** — партнёрство Figma + Anthropic: Code to Canvas конвертирует AI-код в редактируемые Figma-слои
- **Июнь 17, 2026** — крупное обновление: импорт дизайн-систем из GitHub, /design-sync, round-trip с Claude Code, исправление расхода токенов
- **Август 2026** — навык /design в Claude Code (research preview) — артборды в терминале
- **Сентябрь 16, 2026** — Claude Design вливается в основной Claude как тип артефакта
- **Октябрь 15, 2026** — автоматическое включение для Enterprise
- **Декабрь 14, 2026** — закрытие standalone claude.ai/design

**Функциональность:** генерация прототипов, лендингов, презентаций, UI-макетов через диалог. Автоматическое построение дизайн-системы из кодовой базы. Pipeline в Claude Code для имплементации. Экспорт: PDF, URL, PPTX, Canva.

**Ограничения:** нет нативного экспорта в Figma (только через сторонние плагины типа html.to.design). Нет юзабилити-тестирования, тепловых карт, автопроверок доступности.

**Ценообразование:** включён во все тарифы Claude (Free, Pro, Max, Ultra, Team, Enterprise) без отдельной платы.

**Конкуренты:**
- Figma Make — $20/мес (beta), работает внутри Figma, поддерживает Claude Sonnet 4 и Gemini
- v0 (Vercel) — prompt-to-UI генерация
- Adobe Firefly — генеративный AI для визуальных ассетов

**Реакция сообщества:** акции Figma упали на 5–7% после анонса Claude Design. Дизайнеры отмечают: инструмент хорош для быстрых концептов, но Figma остаётся сильнее для командной работы, дизайн-систем в масштабе и handoff разработчикам.

## Выводы

### Что применить в работе дизайнера

1. **Мигрировать дизайн-системы из Claude Design standalone до 14 декабря.** Чаты и комментарии не переносятся — сохранить важное вручную. Это срочная задача для всех, кто использовал claude.ai/design.

2. **Попробовать навык `/design` в Claude Code.** Артборды генерируются в контексте реальной кодовой базы и дизайн-системы проекта. Это не абстрактные макеты — Claude знает ваши токены, компоненты и бренд.

3. **Паттерн Knak: дизайнер прототипирует в коде.** Один профиль + три файла навыков = дизайнер работает в той же среде, что и разработчик. Уменьшает потери при передаче и скоуп-дрифт.

4. ⭐ **ЗАПОМНИТЬ — Handoff-бандл Claude Design → Claude Code.** Дизайн-система, иерархия компонентов и спеки лейаута передаются одной командой. Это заменяет многошаговую ручную передачу макетов. Проверить, насколько полный бандл получается на вашем проекте — инженеры отмечают, что он не всегда полный.

5. **Community skills для рутины:** dark-mode-design для автоматической конвертации, accessibility-audit для WCAG, design-sprint для спринтов. Устанавливаются через `npx -y skills add`.

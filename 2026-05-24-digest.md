## AI Design Tool от Anthropic: трекинг

**Статус:** Claude Design — запущен 17 апреля 2026, research preview.

**Доступность:** Research preview для подписчиков Pro ($20/мес), Max, Team и Enterprise. Адрес: claude.ai/design.

**Движок:** Claude Opus 4.7 (самая мощная визуальная модель Anthropic).

**Функциональность:**
- Генерация UI, лендингов, презентаций, слайдов, one-pagers, интерактивных прототипов из текстового промпта
- Загрузка изображений, документов (DOCX, PPTX, XLSX), анализ кодовой базы
- Web capture для захвата элементов с живого сайта
- Inline-комментарии, прямое редактирование текста, ползунки для spacing/color/layout
- Экспорт в PDF, PowerPoint, HTML
- Handoff в Claude Code для продакшен-имплементации
- Автоматическое построение дизайн-системы из кодовой базы и дизайн-файлов

**Интеграции:**
- Claude Code (handoff из Design в Code)
- Figma — через MCP-сервер (Code to Canvas), но нативной интеграции внутри Claude Design пока нет
- Партнёрство Figma + Anthropic для «Code to Canvas» (анонс февраль 2026, расширение май 2026)

**Ценообразование:** Включено в подписку Pro/Max/Team/Enterprise. Потребляет токены Opus 4.7 — две дизайн-сессии могут съесть ~58% недельной квоты Pro.

**Ограничения:**
- Нет перемещения элементов drag-and-drop (только через промпт)
- Нет предиктивных хитмапов и автоматических аудитов доступности
- Медленная генерация
- Ограниченные токены
- После 4-5 ревизий — дрифт от первоначального замысла

**Конкуренция:**
- Figma ответила запуском нативного AI Design Agent (20 мая 2026) с партнёрствами Anthropic + OpenAI
- Figma: выручка $333.4 млн за Q1 (+46% YoY), повышен прогноз на год
- Профессиональные дизайнеры на Reddit: Claude Design — для быстрой идеации, Figma — для финальной работы

**Реакция сообщества:**
- Figma акции: -4.26% в день запуска Claude Design, но потом восстановление + повышение прогноза
- Дизайнеры: «джуниор ко-дизайнер», не замена Figma
- Нон-дизайнеры (PM, фаундеры): основная целевая аудитория, позитивная реакция

**Свежие новости (20-23 мая):**
- Figma запустила собственный AI Design Agent (бета, бесплатно) — прямой ответ на Claude Design
- Figma открыла API для внешних AI-агентов (Claude Code, Codex) через MCP

## Выводы

### Что применить в работе дизайнера

1. **Figma AI Agent (бета, бесплатно)** — ⭐ **ЗАПОМНИТЬ**. Figma запустила нативного AI-агента, который дизайнит на канвасе через естественный язык. Бесплатно во время бета. Можно запускать несколько агентов параллельно. Это меняет скорость итерации при работе с макетами.

2. **Дизайн-система как Claude Skill** — ⭐ **ЗАПОМНИТЬ**. Ключевой паттерн 2026 года: превращение дизайн-системы в файл-скилл, который автоматически загружается в каждую сессию Claude. Включает токены, правила именования, спеки компонентов, антипаттерны. Для команд — коммитится в репо, одинаковый контекст для всех.

3. **Борьба с «AI slop»** — официальный frontend-design скилл Anthropic банит Inter, Roboto, Arial, Space Grotesk как «затасканные AI-шрифты». Uppercase labels с wide letter-spacing для навигации. Левое выравнивание текста по умолчанию. Semantic tokens для каждого значения цвета, spacing и типографики.

4. **Anchoring-промпт на 4-5 ревизии** — после 4-5 итераций в Claude Design/Code выходы начинают дрейфовать от замысла. Решение: не слоить коррекции, а написать новый «якорный» промпт, фиксирующий ядро замысла.

5. **Claude Design → Claude Code pipeline** — быстрая генерация в Claude Design, затем handoff в Claude Code для продакшен-имплементации. Один разговор вместо недели переписки между брифами, макетами и ревью.

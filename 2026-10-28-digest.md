**Функциональность:**
- Генерация из текста: прототипы, лендинги, слайды, one-pagers, UI-мокапы
- Импорт дизайн-системы: из GitHub-репозитория, дизайн-файлов, прямой загрузки
- Режимы: Prototype, Slide Deck, From Template
- Редактирование: чат, инлайн-комментарии, прямое редактирование на canvas, слайдеры (Tweaks)
- Экспорт: HTML, PDF, PPTX, Canva, хендофф в Claude Code
- Команда `/design` в Claude Code — создание и синхронизация дизайн-проектов из терминала

**Интеграции:**
- Figma (через Code to Canvas, февраль 2026) — перенос UI из Claude Code в редактируемые Figma-фреймы
- Figma MCP — двусторонний доступ к слоям, цветам, компонентам
- Canva, Adobe, Lovable, Miro, Replit, Vercel, Wix
- Microsoft Word и PowerPoint (экспорт)

**Ценообразование:**
- Доступен на всех планах (Free, Pro, Max, Team, Enterprise)
- Использует общий пул лимитов с чатом, Claude Cowork и Claude Code

**Реакция дизайн-сообщества:**
- Хвалят: быстрая генерация вариантов, Tweaks-слайдеры для точной настройки, хороший для ранней стадии
- Критикуют: высокий расход токенов (настройка дизайн-системы «съедает» почти весь лимит), неточный селектор секций, однонаправленный хендофф в Claude Code, не заменяет Figma для пиксельной точности
- Общий консенсус: отличный для exploration и прототипов, не для финального production-дизайна

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Настройка дизайн-системы — первый шаг, не последний.** Множество источников подчёркивают: качество вывода Claude Design напрямую зависит от качества загруженной дизайн-системы. Потратьте время на настройку — это окупится на каждом следующем проекте.

2. **Tweaks вместо re-prompting.** Для микро-правок (шрифты, радиусы, отступы) используйте слайдеры Tweaks и прямое редактирование на canvas. Промпт для каждого изменения — потеря 5-15 минут на генерацию.

3. **Skills как «запрограммированное мышление».** Оформляйте повторяющиеся процессы (аудит, синтез исследований, генерация спеков) как Claude Skills. Один раз описали — используете многократно с предсказуемым качеством.

4. **⭐ ЗАПОМНИТЬ: Claude Design вышел из беты и стал бесплатным.** С октября 2026 Claude Design доступен на всех планах, включая Free. Standalone-версия закрывается 14 декабря — нужно мигрировать дизайн-системы в основной Claude. Это важное окно для всех, кто ещё не попробовал инструмент.

5. **⭐ ЗАПОМНИТЬ: Generic-дизайн — это не вина AI, а вина входных данных.** Тезис из статьи Tridip Thrizu применим к любой работе с AI-дизайном: без контекста бренда, дизайн-системы и качественных промптов результат будет шаблонным. Инвестиция в качество входных данных — главный рычаг.

6. **Figma остаётся центральным инструментом** для pixel-perfect дизайна, командной работы и production. Claude Design и Claude Code — для exploration, прототипирования и первых драфтов. Связка через Figma MCP и Code to Canvas позволяет перемещать работу между инструментами.

| **Ценообразование** | Входит в подписку, расходует общий лимит токенов |

### Функциональность
- **Прототипы**: wireframes, high-fidelity UI, лендинги, одностраничники
- **Презентации**: Claude Slides как отдельная точка входа (бета)
- **Видео**: Claude Motion — анимация прототипов через промпт (бета)
- **Дашборды**: Claude Dashboards — генерация аналитических интерфейсов (бета)
- **Экспорт**: PDF, PPTX, HTML, Canva
- **Handoff**: упаковка в handoff-бандл для Claude Code в один клик
- **Дизайн-системы**: импорт из GitHub, Figma-файлов или загрузка вручную
- **Редактирование**: прямое редактирование на canvas + inline comments + AI-слайдеры
- **Accessibility**: проверка контраста, иерархии, WCAG

### Интеграции
- **Figma**: Code to Canvas (февраль 2026) — двусторонняя конвертация
- **Claude Code**: /design-sync (двусторонняя синхронизация, с июня 2026), /design (UI-макеты в терминале, превью с августа 2026)
- **Canva**: экспорт в Canva (с апреля 2026)
- **Word/PowerPoint**: экспорт в PPTX (с июня 2026)

### Ограничения (по данным обзоров)
- Нет нативного экспорта в Figma (только через Code to Canvas)
- Нет real-time коллаборации (только шаринг по ссылке)
- Нет бесконечного canvas
- Inline comments могут глючить
- Handoff-бандл требует доработки разработчиком

### Сравнения с конкурентами
- **Figma Make** (на Claude Sonnet 4): встроен в Figma, работает с нативными компонентами — лучше для работы внутри существующей дизайн-системы
- **Google Stitch**: аналогичный продукт от Google, вышел в 2026
- **v0 (Vercel)**: фокус на генерации кода, не на визуальном дизайне
- **Adobe Firefly**: фокус на графике и изображениях, не на UI

### Реакция дизайн-сообщества
- Профессиональные UI/UX-дизайнеры: инструмент полезен для быстрого прототипирования, но не заменяет Figma для production-работы
- Не-дизайнеры (PM, маркетологи): главная целевая аудитория, инструмент снижает барьер входа
- Критика: «AI-эстетика» в генерируемых интерфейсах, ограниченные возможности редактирования

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **DESIGN.md + skill.md = бренд-консистентный AI-output** — Главная тема октября. Загрузите свою дизайн-систему (токены, типографику, spacing, цвета) в файл DESIGN.md, создайте skill.md с правилами применения — и Claude Code будет генерировать UI, соответствующий вашему бренду. Это решает проблему «все AI-интерфейсы выглядят одинаково».

2. **UX-воркфлоу как Claude Skills** — Сохраняйте повторяющиеся действия (аудит, критика, подготовка спеков) как skill-файлы. Один раз описали процесс — запускаете одной командой. Особенно полезно для команд с единым стандартом качества.

3. ⭐ **ЗАПОМНИТЬ — Claude Design вышел из беты и стал бесплатным (8 октября)**. Теперь доступен всем пользователям Claude, включая бесплатный тариф. Для дизайнера это означает: можно использовать для быстрого прототипирования идей прямо в чате, без переключения в отдельный инструмент. Дизайн-системы импортируются и сохраняются между сессиями.

4. ⭐ **ЗАПОМНИТЬ — /design в Claude Code (research preview)**. UI-макеты можно создавать прямо в терминале без переключения в браузер. Макеты генерируются как HTML. Это убирает разрыв между проектированием и реализацией для дизайнеров, работающих с кодом.

5. **Claude Motion и Dashboards (бета)** — Новые типы артефактов расширяют возможности: анимация прототипов и генерация аналитических дашбордов. Пока в бете, но стоит следить.

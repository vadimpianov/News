## AI Design Tool от Anthropic — трекинг

### Текущий статус (октябрь 2026)

**Продукт:** Claude Design (ранее AI Design Tool) — запущен 17 апреля 2026 как research preview, работает на Claude Opus 4.7.

**Доступность:**
- Вышел из беты → доступен на всех тарифах (Free, Pro, Max, Team, Enterprise)
- Enterprise: включён по умолчанию с 15 октября 2026
- Standalone-версия (claude.ai/design) закроется 14 декабря 2026
- /design skill в Claude Code — research preview с августа 2026 (v2.1.233+)

**Функциональность:**
- Промпт → интерактивный прототип (HTML/CSS/JS), pitch deck, слайды, one-pager, лендинг
- Импорт дизайн-системы из GitHub-репозитория или Figma URL
- Handoff Bundle → экспорт в Claude Code → production React/Vue
- С сентября 2026 Design работает внутри основного чата Claude (не отдельная страница)
- Claude Motion (бета, 8 октября) — текст/графики → анимированные MP4

**Интеграции:**
- Figma: Code to Canvas (февраль 2026) — код из Claude Code → редактируемые Figma-файлы
- Figma MCP: Claude читает и пишет в Figma-файлы через API
- html.to.design MCP: сторонний мост для пуша дизайнов в Figma с auto layouts и переменными

**Ценообразование:**
- Входит в подписку Claude (Free/Pro/Max/Team/Enterprise)
- Отдельная недельная квота; на Pro-плане хватает на ~2–3 серьёзных проекта в неделю

**Сравнения с конкурентами:**
- vs Figma: Claude Design сильнее в быстром прототайпинге из кода; Figma — в систематической работе с компонентами и командами
- vs v0 (Vercel): v0 — генерация React/Tailwind компонентов для разработчиков; Claude Design — дизайн из контекста кодовой базы
- vs Lovable: Lovable — от идеи до приложения; Claude Design — от кодовой базы до дизайна
- Anthropic утверждает: сложная страница требует 20+ промптов в конкурентных инструментах, 2 в Claude Design (нет подтверждения)

**Реакция дизайн-сообщества:**
- Акции Figma просели после анонса в апреле; напряжённость в партнёрстве (уход Кригера из борда)
- Обзорщики: «полезен, но не угрожает Figma для профессионалов»
- Ограничение: импорт ≠ нативные Figma-компоненты; пока нет pixel-perfect точности

**Новое в октябре 2026:**
- Выход из беты, доступ на Free-плане
- Enterprise default on с 15 октября
- Анонс закрытия standalone-версии (14 декабря)
- Claude Dashboards и Motion в бете (8 октября) — расширяет дизайн-экосистему

## Выводы

### Что применить в работе дизайнера

1. **Claude Design вышел из беты** — если ещё не пробовали, можно начать на бесплатном плане. Основной юзкейс: быстрый прототип из описания → итерации через чат → экспорт в код. Особенно ценно для внутренних инструментов и MVP.

2. **Мигрировать дизайн-системы из standalone-версии** — deadline 14 декабря. Если команда использовала claude.ai/design — пора перенести дизайн-системы в основной Claude.

3. **Taste Skill v2.0.0** — ⭐ **ЗАПОМНИТЬ**: если Claude Code генерирует код с типичной «AI-эстетикой», Taste Skill борется с этим на уровне параметров (layout variance, motion intensity, visual density). Обновление 13 октября изменило поведение параметров — стоит проверить.

4. **Claude Motion для объяснений** — новый инструмент (бета) превращает текст и графики в анимированные видео без генеративных моделей. Потенциально полезен для onboarding-материалов, объяснений UX-решений стейкхолдерам.

5. **Дизайнер как узкое место** — кейс из 36kr показывает реальную проблему: инженеры ускорились с AI, а дизайн отстаёт. Решение — дизайнеры начинают прототипировать в HTML через Claude, сокращая разрыв.

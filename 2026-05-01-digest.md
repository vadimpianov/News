## AI Design Tool от Anthropic — трекинг

### Статус: ЗАПУЩЕН (Research Preview Beta)

- **Название:** Claude Design (ранее упоминался как «AI Design Tool»)
- **Дата запуска:** 17 апреля 2026
- **Стадия:** Research Preview (бета). Не является GA-релизом. Бета-лимиты могут измениться.

### Функциональность
- Генерация прототипов, слайдов, лендингов, one-pagers, маркетинговых материалов через диалог
- Работает на Claude Opus 4.7 (vision model)
- Inline-комментарии на канвасе для итераций
- Кастомные слайдеры для настройки spacing, цвета, лейаута
- Загрузка кодовой базы и Figma-файлов для автоматического извлечения дизайн-системы
- Экспорт: PPTX, PDF, Canva
- Передача implementation bundle в Claude Code (компоненты, дизайн-токены, копирайт, interaction notes)
- Генерация дизайн-системы с нуля или использование существующей

### Интеграции
- **Figma:** «Code to Canvas» (запущен в феврале 2026) — конвертация кода из Claude Code в редактируемые Figma-дизайны. Claude Design также может экспортировать в Figma.
- **Экспорт:** PowerPoint (PPTX), PDF, Canva
- **Claude Code:** прямая передача implementation bundle для кодирования

### Ценообразование
- Доступен для подписчиков Claude Pro, Max, Team, Enterprise
- **Отдельное тарифицирование** от основного Claude — свои лимиты, свой трекинг использования
- Еженедельные allowances, обновляющиеся каждые 7 дней
- Дополнительное использование можно докупить
- Текущие лимиты — бета-лимиты, могут измениться

### Конкурентное окружение
| Инструмент | Позиционирование |
|---|---|
| **Claude Design** | Идеация, быстрые прототипы через диалог, от промпта до прототипа |

## Выводы

### Приёмы, которые можно применить в работе дизайнера

1. **Гибридный воркфлоу Claude Design → Figma:** Использовать Claude Design для быстрой идеации и первых прототипов (upstream), затем переносить в Figma для детальной проработки и командной работы (downstream). Это не замена, а расширение пайплайна.

2. **Дизайн-система как вход для AI:** Загрузка существующей дизайн-системы (токены, типографика, палитра) в Claude Design радикально повышает качество генерируемых прототипов. Без неё результаты generic.

3. **⭐ ЗАПОМНИТЬ: Inline-комментарии вместо текстовых описаний.** Вместо описания изменений в чате — комментирование конкретных элементов прямо на канвасе Claude Design. Это даёт более точные результаты и экономит итерации. Аналогичный подход можно применить при работе с любым AI-инструментом: чем точнее контекст, тем лучше результат.

4. **Цикл Claude Design → Claude Code для соло-дизайнеров.** Один дизайнер может поддерживать до 7 продуктов, используя связку Claude Design (прототип) → Claude Code (реализация). Сокращение цикла до 65%.

5. **⭐ ЗАПОМНИТЬ: Фокус на навыках, которые AI не заменяет.** Пользовательские исследования, переговоры со стейкхолдерами, accessibility-решения, поддержка дизайн-систем для сотен разработчиков — это то, что остаётся за человеком. Junior-дизайнерам критически важно быстро развивать эти навыки.

6. **Hero Prompts для дизайна.** Качество результата Claude Design сильно зависит от качества промпта. Стоит собирать библиотеку проверенных промптов для типовых задач (онбординг, дашборд, лендинг).

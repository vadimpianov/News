## AI Design Tool от Anthropic — отдельный трекинг

### Статус на октябрь 2026

**Продукт:** Claude Design (ранее «AI Design Tool от Anthropic»). Анонсирован 17 апреля 2026 как research preview, работает на Claude Opus 4.7.

**Текущий статус:**
- **Вышел из беты** 8 октября 2026. Доступен на всех планах, включая бесплатный.
- **Enterprise:** включён по умолчанию с 15 октября 2026 (исключение: HIPAA-организации).
- **Standalone-сайт** claude.ai/design закрывается 14 декабря 2026. Дизайн-системы нужно перенести в Claude.

**Функциональность:**
- Генерация прототипов, landing pages, презентаций, one-pagers из текстовых промптов
- Canvas-редактирование с Tweaks-панелью (типографика, радиусы, отступы)
- Inline-комментарии для правок
- Автоматическое извлечение дизайн-систем из загруженных материалов
- Скилл `/design` в Claude Code (research preview с 17 августа)

**Экспорт:** Canva, PDF, PPTX, HTML, Claude Code bundle. **Прямой экспорт в Figma отсутствует** — требуется обходной путь через Claude Code → Figma MCP.

**Новые продукты рядом (бета, октябрь 2026):**
- **Claude Dashboards** — интерактивные дашборды из бизнес-данных (платные планы)
- **Claude Motion** — анимированные объяснители из данных (Team/Enterprise). Генерирует редактируемый код, не видео.

**Интеграции:**
- Figma: через Claude Code + Figma MCP (двунаправленная, с февраля 2026)
- Figma Make использует Claude Sonnet 4 под капотом
- Word/PowerPoint: экспорт через PPTX формат

**Ценообразование:** Входит в тарифы Claude (Free, Pro, Max, Team, Enterprise). Настройка дизайн-системы потребляет значительное количество токенов — по отзывам, может съесть большую часть недельного лимита.

**Сравнение с конкурентами:**
- vs **Figma Make**: Claude Design сильнее в быстром прототипировании из текста; Figma Make — в работе с существующими дизайн-системами и хендоффе
- vs **v0 (Vercel)**: Claude Design ориентирован на дизайнеров (не только код), поддерживает презентации и документы
- vs **Adobe Firefly**: разные ниши — Firefly для генеративных ассетов, Claude Design для UI/прототипов

**Реакция дизайн-сообщества:**
- Акции Figma упали на 7% после анонса в апреле, но затем Figma повысила годовой прогноз
- Дизайнеры оценивают инструмент как полезный для идеации и ранних стадий, но не замену Figma для production-дизайна
- Главные претензии: генерик-стиль по умолчанию, проблемы с accessibility цветов, высокое потребление токенов

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Бренд-гайд как Skill** — загрузить готовые экраны + дизайн-систему в Claude Design, выбрать лучший вариант из трёх и сохранить как переиспользуемый Skill. Решает проблему «дрейфа» к генерик-стилю. Источник: Artificial Corner.

2. **Явный запрос WCAG в промптах** — Claude Design по умолчанию генерирует палитры с плохим контрастом. Добавление «WCAG 2.1 AA compliant colors» в промпт решает проблему. Источник: Medium/@texasbrainsllc.

3. **Tweaks-панель вместо чата для мелких правок** — слайдеры для типографики, spacing и радиусов работают быстрее, чем текстовые запросы. Чат — для структурных изменений. Источник: Muz.li.

4. ⭐ **ЗАПОМНИТЬ — Claude Design вышел из беты**: С 8 октября доступен на всех планах бесплатно. Enterprise включён по умолчанию с 15 октября. Standalone-сайт закрывается 14 декабря — нужно мигрировать дизайн-системы. Это окно для тестирования инструмента до закрытия отдельного сайта.

5. ⭐ **ЗАПОМНИТЬ — Claude Dashboards и Motion**: Два новых инструмента в бете. Dashboards может заменить ручную сборку аналитических дашбордов, Motion — создание объяснительных анимаций. Оба потенциально полезны для дизайнеров, работающих с данными и презентациями.

6. **Скилл-экосистема для дизайнеров растёт** — 6 open-source скиллов (GitHub/Gustavosilveira23) покрывают полный UX-цикл; UX Flow Designer генерирует Mermaid-диаграммы и HTML-вайрфреймы из PRD. Стоит встроить в процесс команды.

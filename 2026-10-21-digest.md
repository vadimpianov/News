## Выводы

### Приёмы, которые можно применить в работе дизайнера:

1. **Design System First** — загрузите дизайн-систему (токены, цвета, типографику) ДО начала генерации в Claude Design. Без этого каждая страница будет стилистически несогласованной. Это подтверждают все практические кейсы из Китая, Японии и англоязычных блогов.

2. **Итеративный подход 3–4 раунда** — первый результат Claude Design всегда черновик. Оптимальный воркфлоу: (1) информационная архитектура и layout, (2) типографика и spacing, (3) цветовая иерархия, (4) микро-взаимодействия.

3. **Claude Code как мост к production** — после прототипа в Claude Design передавайте артефакт в Claude Code для генерации production-кода. Это самый сильный путь handoff в экосистеме Claude.

4. **⭐ ЗАПОМНИТЬ: Figma Specs как контекст для AI** — новая фича Figma (октябрь 2026) позволяет описывать дизайн-правила в Markdown, которые AI-агенты используют как источник правды. Если вы работаете с Claude Code + Figma MCP, создайте Specs для своей дизайн-системы — это повысит качество генерации.

5. **Прототипирование в коде > прототипирование в графике** — тренд: дизайнеры всё чаще строят первый прототип в Claude Code (HTML), а не в Figma. Прототип сразу интерактивный, с shareable-ссылкой, без этапа «оживления».

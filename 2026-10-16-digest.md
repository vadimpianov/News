## AI Design Tool от Anthropic — трекинг

### Статус на 16 октября 2026

**Продукт:** Claude Design (ранее анонсирован как «AI Design Tool»)

**Текущий статус:**
- **GA на всех планах** с 8 октября 2026, включая Free (ранее beta для платных планов)
- **Enterprise default-on** с 15 октября 2026
- Standalone-версия (claude.ai/design) закрывается **14 декабря 2026** — функционал переехал в основное приложение Claude
- Работает на **Claude Opus 4.7**

**Функциональность:**
- Генерация прототипов, слайдов, лендингов, UI из текстовых промптов
- Онбординг дизайн-системы из кодовой базы, Figma-файлов, GitHub-репозиториев
- Уточнение через чат, инлайн-комментарии, прямое редактирование на canvas, слайдеры
- Drag/resize/align элементов (обновление июня 2026)
- Claude Slides — отдельная точка входа для презентаций (сентябрь 2026)

**Интеграции:**
- **Claude Code:** двусторонняя связь через `/design` и `/design-sync`, handoff bundle
- **Экспорт:** PDF, PPTX, HTML, Canva, Miro, Vercel, Wix, Lovable, Replit, Base44, Adobe
- **Figma:** нативного экспорта нет. Workaround через [html.to.design](https://html.to.design/docs/from-claude-ai-to-figma/) плагин
- **Figma Code to Canvas** (партнёрство февраля 2026): позволяет переносить код из Claude Code в редактируемые Figma-дизайны — [CNBC](https://www.cnbc.com/2026/02/17/figma-anthropic-ai-code-designs.html)

**Ценообразование:**
- Включён во все планы (Free, Pro $20/мес, Max $100/$200/мес, Team $30/мес/чел, Enterprise)
- Общий лимит с чатом и Claude Code
- Free: ~1/5 от Pro за 5-часовую сессию

**Сравнения с конкурентами:**
- **vs Figma Make:** Claude Design генерирует код (HTML/CSS/JS), Figma Make — дизайн-файлы (векторы). Figma Make сильнее для команд, работающих в Figma. Claude Design сильнее для code-first подхода — [Magic Patterns](https://www.magicpatterns.com/blog/claude-design-vs-figma-make)
- **vs v0 (Vercel):** Claude Design конкурирует в нише prompt-to-prototype, но ориентирован на полный продуктовый цикл, а не только на UI-генерацию

**Реакция сообщества:**
- Hacker News: скептицизм профессиональных дизайнеров — «не заменяет Figma для precision design work»
- Позитив: «empowers non-designers to make decent designs»
- Более 1 млн пользователей за первую неделю после запуска (апрель 2026)
- Builder.io: хорош для brainstorming, но «начинает сыпаться» при командной работе

- Enterprise default-on (15 октября)

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Design system first — всегда.** Все источники единодушны: без загруженной дизайн-системы Claude Design генерирует generic результат. Загрузка бренда (через GitHub, Figma-файл или URL сайта) — обязательный первый шаг, а не опция.

2. **Два режима итерации.** Чат — для структурных изменений (layout, разделы, направление). Инлайн-комментарии — для точечных правок (padding, цвет кнопки, свопы компонентов). Смешивание режимов замедляет процесс.

3. **Claude Design для exploration, Figma для precision.** Оптимальный пайплайн: Claude Design для быстрых вариантов и wireframes (10–30 мин) → Figma для pixel-perfect доработки → Canva/PPTX для marketing-материалов. Не пытайтесь получить финальный результат из Claude Design напрямую.

4. ⭐ **ЗАПОМНИТЬ: Handoff bundle как стандарт передачи.** Claude Design упаковывает дизайн в bundle (HTML + токены + структура компонентов) и передаёт в Claude Code одной инструкцией. Это устраняет потери при ручной передаче дизайн → код. Стоит изучить этот workflow для своих проектов.

5. **Claude Code /design для быстрых проверок.** Если нужно быстро визуализировать идею без переключения контекста — навык `/design` прямо в терминале. Но учитывайте высокое потребление токенов.

6. **Enterprise-команды: проверьте настройки.** С 15 октября Claude Design включён по умолчанию. Если ваша организация на Enterprise — проверьте, кто имеет доступ, и настройте роли для управления дизайн-системами.

## AI Design Tool от Anthropic: трекинг

### Статус: Research Preview (доступен с 17 апреля 2026)

**Продукт:** Claude Design — инструмент от Anthropic Labs для создания визуального контента через AI.

**Что нового в мае 2026:**
- **Connectors для творческих инструментов:** Anthropic добавил интеграции с Adobe Creative Cloud, Blender, Ableton, Affinity (Canva), Autodesk Fusion через MCP. Claude теперь ближе к файлам и инструментам, которые дизайнеры уже используют.
- **Figma партнёрство продолжается:** Code to Canvas (февраль 2026) + Claude Design (апрель 2026) формируют замкнутый цикл: дизайн → код → дизайн.
- **Figma подняла прогноз на год** после запуска Claude Design (источник: PYMNTS.com) — партнёрство оказалось взаимовыгодным.

**Функциональность:**
- Генерация: прототипы, лендинги, слайды, one-pagers, дизайн-системы, интерактивные сайты
- Технология: HTML/CSS/React, powered by Claude Opus 4.7
- Дизайн-система: импорт кодовой базы и дизайн-файлов, извлечение токенов (цвета, типографика, spacing)
- Handoff Bundle: экспорт в Claude Code для конвертации в production-код
- Интерфейс: чат-панель (левая) + canvas (правая), inline-комментарии, прямые правки

**Ценообразование:**
- Доступен подписчикам Claude Pro, Max, Team, Enterprise
- Потребляет токены агрессивно — рекомендуют не задерживаться в exploration-фазе

**Ограничения (известные):**
- Нет UX-исследовательских фич: предиктивные heatmaps, автоаудит accessibility, usability scores
- «AI-слоп»: дефолтные пресеты дают однотипный вид (teal gradients, serif font)
- Нельзя сдвинуть кнопку на 3px — нет pixel-level контроля
- Нет propagation через shared design system как в Figma

**Сравнение с конкурентами:**
- vs **Figma Make**: Claude Design — для generative moment, Figma Make — для refinement. Разные этапы одного воркфлоу.
- vs **v0 (Vercel)**: Claude Design более заточен под дизайн-системы и имеет handoff в Claude Code.
- vs **Adobe Firefly**: Firefly фокусируется на генеративных изображениях, Claude Design — на интерфейсах и прототипах.

**Реакция дизайн-сообщества:**
- 72% дизайнеров (Dribbble/State of AI Design 2026) используют Claude для код-генерации (было 18%)
- Фрилансеры: 3.8x рост продуктивности; агентства: 62% быстрее хендоффы
- Рост концепции «Super-IC» — один дизайнер с Claude = вывод 3-х человек
- Критика: однотипный визуал, агрессивное потребление токенов, отсутствие pixel-level контроля

## Выводы

### Какие приёмы можно применить в работе дизайнера

1. **Taste Skill как антидот к AI-слопу** — создайте документ с вашими эстетическими предпочтениями (палитра, типографика, spacing, radius) и загружайте его в каждую сессию Claude. Это решает главную проблему — однотипный вид генерации.

2. **«Harness» подход для Figma-воркфлоу** — не просто подключайте Claude к Figma, а создайте enforcement layer из 4 Skills: валидация токенов, проверка компонентов, контроль стилей, применение структуры. Без этого Claude создаёт визуально правильные, но системно некорректные результаты.

3. **Цикл Claude Design → Claude Code → Figma** — три инструмента для трёх этапов: exploration (Claude Design, <1 часа), implementation (Claude Code), refinement (Figma). Не задерживайтесь в одном этапе.

4. ⭐ **ЗАПОМНИТЬ — «Бан заезженных шрифтов»:** Скилл, который банит Inter, Roboto, Arial, Space Grotesk и пушит смелые палитры — конкретный и применимый приём против generic AI-output. Создайте подобный запрет в своём Taste Skill.

5. ⭐ **ЗАПОМНИТЬ — «System first, screens second»:** Подход дизайнера Anthropic Ryan Mather — сначала полная дизайн-система с токенами и page-level overrides, потом генерация экранов. Это то, что отличает generic output от on-brand дизайна.

6. **Фиксируйте tokens до экранов** — lock design tokens (цвета, типографика, spacing, radius) прежде чем строить любые экраны. 8px base grid, primary/secondary typefaces, accent colors — всё должно быть определено заранее.

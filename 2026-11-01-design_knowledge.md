## 1. Компоненты & Паттерны

**Принцип:** Вместо расплывчатого фидбэка («теплее», «поярче») создавайте интерактивные контролы (слайдеры, переключатели) для управления визуальными параметрами — это превращает субъективное обсуждение в конкретное решение.

**Почему:** Nate Parrott (Anthropic) описывает, как в эксперименте с цветом команда заменила цепочку сообщений «сделай теплее» на слайдер-контрол. Это устранило двусмысленность и ускорило принятие решения. Применимо не только к AI-воркфлоу — любой ревью с клиентом выиграет от конкретных контролов вместо субъективных описаний.

**Источник:** [How the product designer who built Claude Design uses it](https://claude.com/blog/how-the-product-designer-who-built-claude-design-uses-it-to-explore-ideas-before-building-them)

**Дата:** 2026-11-01

## 2. Figma-техники / Дизайн-системы

**Принцип:** Выравнивайте Figma-переменные (variables) с CSS-токенами один-к-одному — это создаёт единый дизайн-словарь для людей и AI-инструментов, устраняя расхождения при передаче в разработку.

**Почему:** Автор из UX Collective описывает, как синхронизация Figma variables с CSS custom properties позволила Claude Code, Codex CLI и MCP-серверу работать с одним словарём. Без этого AI генерирует произвольные значения. Принцип полезен и без AI — точное соответствие переменных уменьшает ошибки handoff.

**Источник:** [Building AI-driven workflows powered by Claude Code and other tools](https://uxdesign.cc/designing-with-claude-code-and-codex-cli-building-ai-driven-workflows-powered-by-code-connect-ui-f10c136ec11f)

**Дата:** 2026-11-01

## 3. Компоненты & Паттерны

**Принцип:** Дизайн-система должна быть загружена как контекст для любого AI-инструмента ДО начала генерации — без неё выход будет generic и отклонится от продукта.

**Почему:** Несколько независимых кейсов (GitLab, Brilliant, независимый обзор в Substack) подтверждают одно: Claude Design без дизайн-системы генерирует «среднестатистический» UI. С загруженной системой — прототипы из реальных компонентов. Принцип распространяется на любой AI-инструмент: контекст определяет качество.

**Источник:** [Weekly AI Bites #5: Building a design system with Claude Design](https://productbuildersainative.substack.com/p/weekly-ai-bite-5-building-a-design)
